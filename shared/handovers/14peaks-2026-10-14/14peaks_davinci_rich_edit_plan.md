# 《14峰》DaVinci 粗剪执行方案 V1

> 目标：把《14 Peaks: Nothing Is Impossible》做成约 10 分钟中文纪录片二创解说。  
> 风格：按涛哥「户外创作团队」方向，人物故事 + 户外纪录片解说 + 关键数据花字 + 克制电影感。  
> 画幅建议：优先 16：9 横屏；如做抖音长内容。  
> 本方案用于 DaVinci Resolve AI/MCP 粗剪，不要求一次成片，重点是先把素材、口播、字幕、花字、转场、音效结构搭好。

---

## 一、全片剪辑策略

### 1.1 时间线设置

| 项目 | 建议 |
|---|---|
| 时间线 | 1080x1920，25fps，9:16 |
| 主视频轨 V1 | 原纪录片画面 |
| V2 | 放大裁切/局部特写/地图图层/资料图 |
| V3 | 花字、人物标注、数据字卡 |
| V4 | 黑场白字、章节卡、路线图 |
| A1 | AI中文口播 |
| A2 | 原片同期声，保留关键英文/尼泊尔语情绪点 |
| A3 | BGM |
| A4 | 音效：低频冲击、风声、whoosh、字卡打击、无线电噪声 |

### 1.2 调色与画面处理

| 场景 | 调色 |
|---|---|
| 雪山/高海拔 | 冷色、低饱和、提高高光细节，保留雪面层次 |
| 采访/家庭 | 暖一点，降低对比，保留皮肤质感 |
| 危险/救援/K2 | 对比稍高，阴影压暗，增加冷蓝/青色氛围 |
| 结尾/团队庆祝 | 稍微回暖，亮度抬起，情绪收束 |

### 1.3 字幕与花字原则

| 类型 | 用法 |
|---|---|
| 底部字幕 | 中文口播逐句字幕，白字黑描边，底部居中 |
| 数据花字 | 只打数字和结论：14座、8000米、7个月、6个月零6天、48小时、K2 |
| 人物标注 | 首次出现 Nims / Mingma / Geljen / Suchi / 母亲时出现 |
| 地点标注 | 左下角：Annapurna / Everest / K2 / Shishapangma |
| 章节卡 | 黑场白字或雪山画面叠字，不超过 1 秒 |

### 1.4 转场原则

| 转场 | 使用场景 |
|---|---|
| 硬切 | 大部分叙事推进 |
| 黑场白字 | 章节切换、时间/阶段切换 |
| 慢推/慢拉 | 雪山远景、人物静态、情绪段 |
| 地图/路线转场 | 山峰之间切换 |
| Whoosh + 快切 | 数据密集段、14座山名单、阶段推进 |
