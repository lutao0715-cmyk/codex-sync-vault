# 红头文件一体化生成指南

> **这份文件解决什么**：`gb-t9704-format.md` 讲了红头（版头）**该长什么样**，
> 但没说**怎么一步步做出来**。用户说「出一份红头文件」时，光有规范是不够的——
> 需要按什么顺序问、哪些要素必填、要素之间怎么排、最后怎么落到 Word 里。
> 本文就是这段「从规范到成品」的可执行路径。

---

## 一、先明确：红头文件 = 版头 + 主体 + 版记

| 部分 | 含哪些要素 | 本文档负责 |
|------|-----------|:---------:|
| **版头** | 份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人、红色分隔线 | ✅ **重点** |
| **主体** | 标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注 | 详见 `gb-t9704-format.md` §三 |
| **版记** | 抄送机关、印发机关和印发日期 | 详见 `gb-t9704-format.md` §四 |

**用户开口说「红头文件」时，通常只关心版头要不要、长什么样**。主体按常规公文写即可。

---

## 二、三类红头（先判断用哪种）

| 类型 | 特征 | 适用 | 版心宽 |
|------|------|------|:------:|
| **通用红头（文件式）** | 单条红色分隔线；发文机关标志 + 「文件」 | 下行文、上行文，绝大多数正式公文 | 156mm |
| **信函式红头** | **双线**（上粗下细 + 上细下粗）；无「文件」二字 | 平行文、便函 | 170mm |
| **联合行文红头** | 多机关名称并列，主办在前；只用主办机关发文字号 | 两个及以上单位联合发文 | 156mm |

> **判断口诀**：**正式发文看「文件式」，平级商洽看「信函式」，多家联署看「联合式」。**
> 拿不准就直接问用户「是单位正式发文，还是平级单位之间商洽的函？」

---

## 三、必填要素自查表（开工前逐项确认）

**填不出也别卡住**——标「待补」继续往下做，交付时统一提示补全。

| # | 要素 | 是否必填 | 说明 | 本例 |
|:-:|------|:--------:|------|------|
| 1 | **发文机关全称** | ✅ 必填 | 用规范全称，不用简称 | 中兵智能创新研究院 |
| 2 | **发文字号** | ✅ 必填 | 机关代字〔年份〕序号，**年份用六角括号〔〕** | 兵智院〔2026〕15号 |
| 3 | **密级** | ⚠️ 按需 | 无密级则不标（**不写"公开"**） | 秘密 |
| 4 | **保密期限** | ⚠️ 按需 | 与密级同标，格式「机密★5年」 | ★1年 |
| 5 | **紧急程度** | ⚠️ 按需 | 特急 / 加急；无则不标 | 加急 |
| 6 | **份号** | ⚠️ 按需 | **涉密公文必须标**；6 位阿拉伯数字 | 000015 |
| 7 | **签发人** | ⚠️ 看行文方向 | **仅上行文（请示、报告）标**；下行文不标 | 张XX |
| 8 | **标题** | ✅ 必填 | 发文机关+事由+文种 | 关于XX工作的通知 |
| 9 | **主送机关** | ✅ 必填 | 顶格，末尾加全角冒号 | 各部门、各所属单位： |
| 10 | **成文日期** | ✅ 必填 | 阿拉伯数字，标全年月日 | 2026年9月25日 |
| 11 | **抄送机关** | ⚠️ 按需 | 版记部分 | 无 |

### 三条高频易错规则

1. **密级不写"公开"** —— 无密级就整行不出现，写"公开"反而不规范。
2. **签发人只有上行文才标** —— 下行文标签发人是常见错误。
3. **份号与密级配对** —— 涉密公文必须标份号，份号位数全单位统一（6 位或 3 位，按本单位标准）。

## 四、版头要素编排顺序（从上到下，照着排）

```
┌──────────────────────────────────────┐
│ 000015          ← 份号（3号黑体，左顶格，版心左上第一行）
│ 秘密★1年        ← 密级和保密期限（3号黑体，左顶格，第二行）
│ 加急            ← 紧急程度（3号黑体，左顶格，第三行）
│                                      │
│                                      │  ← 上边缘距版心上边缘 35mm
│      XXXXXX 文件     ← 发文机关标志（红色，小初或一号方正小标宋简体，居中）
│                                      │
│                                      │  ← 下空 2 行
│       兵智院〔2026〕15号   张XX   ← 发文字号（3号仿宋_GB2312，居中）＋ 签发人（仅上行文）
│                                      │  ← 下空 4mm
│ ════════════════════════════════  ← 红色分隔线（与版心等宽，线高 0.35-0.5mm）
└──────────────────────────────────────┘
                  ↓ 下空 2 行
              标  题（二号方正小标宋简体，居中，固定行距 30 磅）
                  ↓ 下空 1 行
        各部门、各所属单位：（3号仿宋_GB2312，左顶格）
```

### 要素位置与字体速查

| 要素 | 位置 | 字体 | 字号 | 颜色 |
|------|------|------|:----:|:----:|
| 份号 | 版心左上第一行 | 黑体 | 3 号 | 黑 |
| 密级和保密期限 | 版心左上第二行 | 黑体 | 3 号 | 黑 |
| 紧急程度 | 密级下方 | 黑体 | 3 号 | 黑 |
| **发文机关标志** | 上边缘距版心上边缘 35mm，居中 | **方正小标宋简体** | 小初 / 一号 | **红** |
| 发文字号 | 发文机关标志下空 2 行，居中 | 仿宋_GB2312 | 3 号 | 黑 |
| 签发人（"签发人"三字） | 与发文字号同行，右侧 | 仿宋_GB2312 | 3 号 | 黑 |
| 签发人（姓名） | 同上 | **楷体_GB2312** | 3 号 | 黑 |
| **红色分隔线** | 发文字号下 4mm，与版心等宽 | — | 线高 0.35-0.5mm | **红** |
| 标题 | 分隔线下空 2 行，居中 | 方正小标宋简体 | 二号 | 黑 |
| 主送机关 | 标题下空 1 行，左顶格 | 仿宋_GB2312 | 3 号 | 黑 |

## 五、置入 Word 的具体做法

### 做法 A：让 AI 直接产出国标 docx（推荐）

生成文档时按下列参数设置，版头要素用**首行段落 + 居中对齐**实现：

| 步骤 | 操作 | 参数 |
|:----:|------|------|
| 1 | 页面设置 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm |
| 2 | 份号段落 | 左对齐，黑体 3 号（16pt），无缩进 |
| 3 | 密级段落 | 左对齐，黑体 3 号，无缩进 |
| 4 | 空行 | 2 行（3 号字行） |
| 5 | 发文机关标志 | 居中，方正小标宋简体，小初（36pt）或一号（26pt），**字体颜色设为红色 RGB(255,0,0)** |
| 6 | 空行 | 2 行 |
| 7 | 发文字号 | 居中，仿宋_GB2312 3 号（16pt） |
| 8 | **红色分隔线** | 插入一条**与版心等宽的红色横线**：Word 中用「段落边框-下框线」设为红色、宽度 0.5mm（1.5pt），或插入 1 行 1 列表格设下边框 |
| 9 | 空行 | 2 行 |
| 10 | 标题 | 居中，方正小标宋简体 二号（22pt），固定行距 30 磅 |
| 11 | 主送机关 | 左顶格，仿宋_GB2312 3 号（16pt） |

> **关键点**：红色分隔线不要用符号（如 `━━━━`）拼，**用段落下边框或表格下边框**，
> 这样才能保证与版心等宽、线高可控、打印不断线。

### 做法 B：交给 Word/WPS 模板

若单位已有红头模板（.dotx / .wpt），**优先沿用模板**——红头部分已排好，
只要把标题、主送机关、正文、落款填进去即可，避免字体与线宽偏差。

### 做法 C：手工置入（最后手段）

按第四节顺序手动敲，注意三处：
- 发文机关标志**颜色必须手动设红**（默认黑）
- 分隔线用「插入-形状-直线」或段落边框，**线长设为 15.6cm**（版心宽 156mm）
- 标题与正文**行距分设**：标题固定 30 磅、正文固定 28 磅

## 六、字体不可用怎么办（重要，务必先查）

**方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体为本技能默认字体，但均为商用授权字体。**

| 情况 | 处理 |
|------|------|
| 本机已装国标字体 | 直接用，无需处理 |
| 本机未装 | 先用替代字体生成，**并在交付时明确告知已替代** |
| 用户要求嵌入字体 | **拒绝嵌入商用字体**，改为告知替代方案或由用户自行设置 |

### 替代对照表

| 国标字体 | 替代方案 | 影响 |
|---------|---------|------|
| 方正小标宋简体 | 华文中宋 / 宋体加粗 | 笔形略有差异，不影响识别 |
| 仿宋_GB2312 | 仿宋 | 基本一致 |
| 楷体_GB2312 | 楷体 | 基本一致 |
| 黑体 | 黑体（系统自带） | 通常无差异 |

> 先跑 `python scripts/preflight_check.py` 探测本机字体槽位，再决定是否替代。
> 详细降级说明见 `references/troubleshooting.md`。

## 七、交付前自检（6 项）

生成红头文件后，逐项核对：

- [ ] **发文字号**年份用的是**六角括号〔〕**，不是方括号[]或圆括号（）
- [ ] **涉密公文标了份号**；非涉密未标（且没写"公开"）
- [ ] **密级与保密期限同行**（如"秘密★1年"）
- [ ] **签发人只在上行文出现**（请示/报告），下行文没有
- [ ] **红色分隔线**与版心等宽、颜色为红、粗细 0.35-0.5mm
- [ ] **标题行距 30 磅、正文行距 28 磅**（两者不同，别统一）

### 自动校验

```bash
# 版头要素校验（V-1.9.0 新增，检查份号/密级/括号/分隔线等）
python scripts/format_check.py 红头文件.docx

# 一次性跑全部校验
python scripts/format_check.py 红头文件.docx && python scripts/quality_score.py 红头文件.docx
```

`format_check.py` 会检测的版头项：发文字号括号类型、密级与保密期限配套、份号位数、
签发人是否用于下行文、分隔线是否存在。**检测结果仅作提示，最终须人工确认。**

## 八、常见错误对照

| 错误 | 正确 | 后果 |
|------|------|------|
| 发文字号用「兵智院[2026]15号」 | 「兵智院〔2026〕15号」 | 格式不规范，归档被退 |
| 无密级却写"密级：公开" | 整行不出现 | 多此一举，反而不规范 |
| 下行文标注签发人 | 只有上行文标 | 概念错误 |
| 涉密公文不标份号 | 必须标份号 | 违反保密规定 |
| 分隔线用 `━━━` 符号拼 | 用段落边框/表格边框 | 打印断线、宽度不一 |
| 标题行距设 28 磅 | 标题 30 磅、正文 28 磅 | 与国标不符 |
| 发文机关标志用黑色 | 必须设为红色 | 红头变"黑头" |
| 信函式用了单线 | 信函式用双线 | 文种版式不匹配 |

## 九、快速调用示例

**用户说**：「帮我出一份红头文件，我们是中兵智能创新研究院，发个关于国庆假期值班安排的通知」

**AI 应做**：
1. 判断类型 → 单位正式发文 → **通用文件式**
2. 从表述中提取：发文机关=中兵智能创新研究院、文种=通知、事由=国庆假期值班安排
3. 询问缺失项：**发文字号序号**、**是否涉密**、**紧急程度**、**主送范围**（四项，一次问完）
4. 生成 docx，按第五节做法 A 设置版头
5. 跑 `format_check.py` 校验
6. 交付时列出自检 6 项结果 + 缺失项待补提示

**产出效果**：
```
                    中兵智能创新研究院文件

                    兵智院〔2026〕XX号
    ══════════════════════════════════════

              关于2026年国庆假期值班安排的通知

    各部门、各所属单位：
    ...
```
