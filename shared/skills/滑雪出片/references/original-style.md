# 一、写作特征（脚本创作方式）

## 1.1 七种开头钩子（全部有实例）

| # | 类型 | 实例 |
|---|---|---|
| 1 | **第一人称情绪切入 + 悬念** | 「这是我最近听到一个最令我震惊的关于冬奥会梦想的故事。」 |
| 2 | **称号式人物开场** | 「他被誉为滑雪界的钢铁侠，是全世界最潇洒的自由式滑雪运动员。」 |
| 3 | **单反问开场** | 「在所有的冬奥会比赛项目中，有哪个项目是危险系数最高的？」 |
| 4 | **向观众抛个人议题** | 「今天跟大家聊一个很现实的问题，如果你现在正在以滑雪为生，未来你会让你的家人跟小孩也跟你一样把滑雪当做自己的职业吗？」 |
| 5 | **共识铺垫 + 替观众发问** | 「相信很多刚接触滑雪的小伙伴们一定听过这句话…不明所以的你，这时候一定会问了。」 |
| 6 | **电影式场景描写** | 「2002 年的一个清晨，一架救援直升机从阿拉斯加圣伊莱亚斯的雪山山顶飞过。」 |
| 7 | **连续反问轰炸（3 连问）** | 「你见过一部纪录片里面有一半出现的人，在现实生活中都因为意外死亡的吗？你能想象一部电影在还未发布之前，就已经有多位主角因故去世了吗？你知道当人类穿上双板滑雪板的那一刻，他们究竟能干出多少匪夷所思的事情吗？」 |

→ **规律**：情感/人物类走 ①②⑤；知识/历史类走 ③⑦；纪录片解说走 ⑥。
**他不写"大家好我是XX"这种自我介绍式开场。**

## 1.2 叙事结构

| 结构 | 怎么走 | 实例 |
|---|---|---|
| **生平时间线** | 出生年 → 关键年份 → 转折 → 现在 | 下载(1)：1982 年出生 → 20 岁 X Games 夺冠 → 2011 年结识岳父 → 创办 Douchebag → 现在 |
| **共识 → 逐条论证 → 推翻 → 反问收口** | 先立"大家都这么说"，再用解剖/工学逐条拆，最后明确表态 | 下载(4)：双板单板入门难度 |
| **悬念前置 + 倒叙** | 先给信息量最大的画面，再回头铺背景 | 下载(5)：2002 年清晨「TO DEAD」→ 讲这座山 → 回到那支队伍 |
| **年份硬切分段** | 用年份/时间锚点切段，不做过渡句 | 「2011 年」「2009 年」「1991 年冬天」「1998 年」 |
| **编号清单 + 单点补料** | 直给痛点 → 1/2/3 逐条 → 每条追加一句"难点"或"彩蛋" | 下载(10)：双板十大平花技巧，每条都带「这个动作很难，但练起来绝对很帅」 |
| **先驱递进式（史观叙事）** | 一个人接一个人往下推，每人都以"把大山赐予的一切还给大山"收束 | 下载(9)：比尔·布里奇斯 → 瓦伦卡 → 格林佩雅 → Doug Coombs → 肖恩·麦康基 |

## 1.3 语言指纹（最像他的地方）

**① 第一人称是叙事主体，不是旁观**
「我最近听到」「我就好奇点击他的头像」「今天就让我来带大家看看」「我在视频的开头也说过」

**② 明确标注个人立场 —— 这是他最鲜明的一个特征**
- 「其实我个人对于这个观点来说，并不是完全的认同」
- 「我绝不认同双板进阶要比单板难」
- 「我该很负责任地跟你打包票」
- 「我跟大家说」

→ 他**不做中立科普**。有观点就亮出来，而且敢说"我不同意"。

**③「我们」拉近距离**
「我们都知道世界最高峰是珠穆朗玛峰」「我们日常的行走或者跑步姿势」

**④ 数字密度高，且具体到能感知**
390 万欧元 / 150 万粉丝 / 近 5000 万美元 / 8848 米 / 5500 米落差 / 130 公里每小时 /
「2.5 米宽的洞口一个小时不到就被盖得只剩几十厘米」/ 40 小时飞机 / 3 万公里 / 两次拒签 / 26 岁

**⑤ 比喻一律通俗化，不玩文艺**
「跟吃饭喝水一样简单」「就跟坐过山车一样」「雪花又如黄虫一般铺天盖地」

**⑥ 绝对化用语不回避 —— 但也只在情绪高点用**
史上最牛逼 / 第一巨富 / 不要命 / 唯一一人 / 天花板级别 / 全能之王

**⑦ 网络口语与自嘲**
「好兄弟们」「格格的人生我的梦」「华华公子」「雪道上最亮的双板仔」

**⑧ 英文原词、片名、术语直接保留**
X Games / LVMH / TGR / Deeper, Further, Higher / Free Ride / Slash / Nose Bust 360

**⑨ 口头连接词高频**
好了 / 所以说 / 其实 / 确实 / 但 / 而 / 同时 / 然后 / 更 / 首先 / 也正因

## 1.4 四种收口

| 类型 | 做法 | 实例 |
|---|---|---|
| **升华回扣** | 从具体事件拔到普世句 | 「恐惧是身体的本能，但勇气才是人类的赞歌」／「他们不是退却，而是一往无前」 |
| **拉到观众身上 + 祝福** | 从人物转回看视频的人 | 「最后也祝各位好兄弟们能早日过上这样的幸福生活」 |
| **反问收口** | 把问题还给观众 | 「你现在听懂为什么有的人说双板难，又为什么有的人说单板难了吗？」 |
| **片源致谢 + 引导** | 交代素材出处，导流看原片 | 「本期视频所有素材大部分来自于 2007 年上映的纪录片…如果大家有兴趣的可以去看看原片」 |

→ **几乎不出现"点赞关注转发"式硬 CTA。** 引流靠内容本身和片源推荐。

## 1.5 内容类型 → 结构映射（写作时的选型表）

| 内容类型 | 开场 | 主体 | 收口 | 语速 |
|---|---|---|---|---|
| **人物传记 / 豪门** | 称号式 | 生平时间线 + 财富成就数字 | 祝福 / 拉到观众 | 6.1–6.3 |
| **历史讲解 / 事故** | 反问或场景 | 年份锚点推进 + 事故细节 + 追问责任 | 升华 / 追问 | 6.4–7.1 |
| **滑雪科普** | 共识或疑问 | 逐条论证 + 明确个人观点 | 反问 | 6.4 |
| **纪录片解说** | 场景描写 | 原声穿插 + 情绪递进 | 诗意升华 | 4.8 |
| **教学 / 盘点** | 直给痛点 | 编号清单 + 单点补料 | 激励 | 短，密度高 |

# 二、配音风格（声学测量）

## 2.1 硬指标

样本：**11 条完整成片，41 分钟语音，15119 字**

| 指标 | 实测 | 含义 |
|---|---|---|
| **全局语速** | **6.10 字/秒** | 区间 **4.58 – 7.13** |
| 最快 | 7.13 / 7.03 / 6.70 | 第一人称叙事、历史推进 |
| 最慢 | **4.58**（纪录片解说） | 抒情段明显压慢 |
| **基频中位** | 116.8 – 148.1 Hz | 男声，偏高；148Hz 出现在最"中二"那条 |
| **音调起伏 CV** | **0.35 – 0.57** | ★ 极高。音调夸张、戏剧化，**绝不平铺直叙** |
| **能量动态** | 6.3 – 13.0 dB | 有明确重音与强弱对比 |
| **语句段均长** | **1.08 – 4.15 秒** | 短句连发为主，不写长句 |
| **最长停顿** | 0.30 – 4.55 秒 | 抒情段敢留白 4 秒以上 |
| **说话占比** | 0.64 – 0.97 | 口播型 0.87–0.97；纪录片型 0.64（近四成留给原片素材） |

## 2.2 关键结论：商单那个 4.9 不算数

坦博尔商单算出的 **4.9 字/秒**，与他原创作品的 **6.10 字/秒** 差了 **24%**。
→ **4.9 是甲方要求他放慢的结果。他自然的叙事语速是 6.1–7.1。**
→ **脚本生成器的默认语速改为 6.1 字/秒；纪录片体裁用 4.6。**

## 2.4 配音执行要点

- **不要均衡输出。** CV 0.35–0.57 意味着音调要大幅起落——每段都要有高点和低点
- **语速跟着体裁换挡**：叙事/科普 6.1–7.1，纪录片 4.6–4.8。全片一个速度是错的
- **句子要短。** 语句段均长 1.1–2.8 秒是常态，最长也就 4 秒
- **重音砸在数字和绝对化词上**（"390 万欧元""唯一一人""史上最牛逼"）
- **抒情段敢留白**，最长停顿可到 4 秒以上
- **纪录片类保留原片原声 + 中文字幕**（下载(5) 多处英文原声直出；下载(8) 近四成时长给了原片）

# 三、BGM 使用风格

## 3.1 曲库画像（22 首可解析，共 21.9 分钟）

| 指标 | 中位值 | 区间 |
|---|---|---|
| 速度 | **100.1 BPM** | 62.5 – 166.7 |
| 能量动态 | **17.8 dB** | 11.7 – 38.5 |
| 低频占比 | 24.0% | 1.8 – 59.7% |
| 频谱重心 | 1530 Hz | 682 – 3426 |

## 3.2 四个曲池（按用途分）

**① 滑雪电影配乐 —— 主力曲池（Andreas Frei 全套 5 首）**

| 曲目 | BPM | 动态 | 低频 | 适合段落 |
|---|---|---|---|---|
| Avalanche | 142.9 | 21.7dB | 34.1% | 高速滑降、冲坡 |
| Final Descent | 103.4 | 29.2dB | **59.7%** | 最厚重的下坠感、危险段落 |
| Exposed | 115.4 | 19.1dB | 24.1% | 探索、暴露在自然中 |
| Finale | 75.0 | 26.9dB | 32.2% | 收尾、总结、落幕 |
| Tragedy Introduction | 68.2 | 14.9dB | 32.0% | 事故、噩耗、转入沉郁 |

- 久石让《The Rain》83.3BPM｜重心 1559Hz
- S.E.N.S.《Wish》62.5BPM｜重心 760Hz（最暗最柔）

- 维瓦尔第《冬》69.8BPM｜重心 2698Hz（明亮古典）

## 3.3 品味结论

1. **主体是"电影配乐"，不是流行歌。** 22 首里流行曲只占 3 首（The Weeknd、Kadebostany、瑜伽氛围）。
2. **速度带很宽（62–167），但主力落在 68–120 BPM 的中慢区间** —— 抒情与推进兼顾。
3. **极度看重大动态（build-up）。** 中位 17.8dB 明显高于普通流行歌（通常 8–12dB）。
   这解释了为什么配乐能"顶"起来 —— 他要的是**有起伏的叙事型音乐**。
4. **不排斥厚重低频。** Andreas Frei 那几首低频 24–60%，Final Descent 接近六成。
5. **情感段落一律靠日系钢琴/弦乐压下来**（久石让、S.E.N.S.）——这是他的"降温键"。

## 3.4 使用规律

- **全程铺底，人声始终压过音乐。** 实测：无口播段落的能量比说话段低 **15dB**
  （下载(5)：说话 -16.2dB vs 空档 -32.0dB；下载.mp4：-13.0dB vs -28.1dB）
  → 背景音约为口播的 **1/5 音量**，是"垫底"不是"并肩"
- **空档占比很低（口播型仅 1.4–3.1%）**，说明音乐几乎不单独出现，永远在口播底下
- **按段落换曲**：推进段 → 史诗/滑雪电影配乐；情感段 → 日系抒情；事故/噩耗 → Tragedy 类
- 曲库自筛，**可信度最高**（这是他自己一首首挑的）

> ⚠️ 上面"无口播段 15dB 低"能证明**背景有持续声源且被压低**，
> 但**不能 100% 区分"BGM"还是"环境音/原片底噪"**。这是推断，不是铁证。

**→ 配乐选曲流程**：
```
段落情绪 → 曲池      → 参考 BPM     → 备选
推进/燃  → ①滑雪电影 → 100–160     → Avalanche / Scorponok
高潮/史诗 → ②史诗预告 → 90–120      → Immortal / An Unfinished Life
探索/壮阔 → ①滑雪电影 → 100–120     → Exposed
事故/沉郁 → ①Tragedy + ③S.E.N.S.    → 68 / 62.5
收尾/升华 → ①Finale + ③久石让        → 75 / 83
```

# 四、一句话总结

> **他是"有观点的说书人"，不是"客观的讲解员"。**
>
> 开场用第一人称或反问把人拽进来，中段用年份和数字把故事砸实，
> 短句连发、语速 6.1 字/秒、音调起伏极大、敢下狠判断，最后用一句普世句收上去。
> 配乐永远是电影配乐——要有 build-up，情绪段切日系钢琴。
