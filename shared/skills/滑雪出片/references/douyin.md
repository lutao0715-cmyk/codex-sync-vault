# 抖音版规范 · 滑雪研究院

## 一、平台逻辑

推荐流产品。标签决定**分发给谁**（首批人群），内容数据（完播、互动、关注转化）决定**能不能晋级下一个流量池**。

推论：
- 前 3 秒决定完播，**钩子必须在 3 秒内出冲突或悬念**
- 标签只定起跑位置 → **他实际只用 1~3 个**（见下）
- **不带无关大热门**。热度越高越泛，打散人群精准度，完播率崩在第一级流量池

## 二、内容定位 ✅（按真实作品校正）

**主线是"讲人和故事"，不是"教技术"。** 从 5 条原创作品看（见 `originals.md`）：

| 方向 | 占比 | 真实例子 | 数据特征 |
|---|---|---|---|
| **人物传奇 / 豪门故事** | 主力 | 单板滑雪公园之王 公子世无双／滑雪界第一巨富的生活／全球第一滑雪世家 | 稳定 1.2~1.7 万赞 |
| **盘点 / 榜单** | 常见 | 滑雪史上最牛逼的十个动作 | **收藏、转发远高于评论** |
| **情感故事** | 出爆款 | 「一个人征战冬奥会的故事」 | 172 万赞，**评论远高于收藏** |
| **赛事节点** | 借势 | 冬奥会相关（4/5 条带 #冬奥会） | — |

**底层驱动是"想知道"，不是"想学会"**：谁是这个人、他家为什么这么牛、史上最猛的动作是什么。
（对比：小红书是"想学会"——见 `xiaohongshu.md`）

⚠️ **不做**：泛户外内容（徒步/露营/桨板）——那是户外号的地盘，两号内容复制会被矩阵同质识别互相压制。

## 三、标题写法 ✅（真实，见 `corpus.md` 第一节）

五种定型句式，核心特征是**敢下最狠的判断 + 江湖气用词**：

- 武侠称号式：`单板滑雪公园之王 公子世无双`
- 共鸣感叹 + 身份：`他的生活我的梦 滑雪界第一巨富的生活`
- 最高级 + 夸张口语：`全球第一滑雪世家，家族里一个比一个不要命！`
- 盘点 + 强度词：`滑雪史上最牛逼的十个动作！`
- 第一人称情感：`这是我最近听到最让我感动的……希望每个人都能被命运眷顾`

⚠️ **不要因为"绝对化用语"而软化标题**——那是商单 Brief 的规矩，不是他的习惯。

## 四、标签规范 ✅（已校正）

**只用 1~3 个。**

| 场景 | 标签 |
|---|---|
| 常态 | `#滑雪` |
| 冬奥/赛事期 | `#滑雪` `#冬奥会`（+`#北京冬奥会`） |
| 加 1 个内容相关 | 如 `#jones_snowboards` |
| 平台活动期 | 加官方活动话题（如 `#相约冰雪一起来`） |

**第 5 条作品只带了一个 `#滑雪`。** → **不要建议他堆标签**，他自己就懂。

## 五、结构模板（⚠️ 来自商单，未在原创中验证）

**A. 故事/人物片（90~160 秒）**
```
钩子(≤16s) → 事件结果前置 → 代价/细节 → 桥接 → 身份 → 资产罗列 → 收口双线合一 → 落点(5s)
```

**B. 观点/知识片（45~90 秒）**
```
钩子(≤8s) → 抛问题 → 给结论(先说答案) → 论证 → 翻一层 → CTA
```

**C. 装备/产品片（60~120 秒）**
```
钩子 → 痛点共鸣 → 转折(直到…) → 卖点逐个砸 → 效果对比 → 升华 → 搜索引导
```

⚠️ 这三套**是从商单脚本反推的**，原创口播素材还没有，**当成假设用**。

## 六、发布要素

- 画幅 9:16，1080p
- 前 3 秒要有画面冲击或强信息
- 品牌合作必须标"广而告之"/"品牌合作"
- 评论区置顶引导（品牌类含搜索词【XXX】）

## 七、什么季节做什么

- **雪季（约 11 月中 ~ 次年 4 月）**：主攻实拍 + 赛事 + 人物内容
- **非雪季**：人物传奇、盘点、历史经典赛事复盘——**这类内容不受季节限制**，是蓄水主力
  - 常驻标签：`#滑雪`（+ 内容相关 1 个）

## 八、禁忌

- ❌ 带无关挑战标签（舞蹈类、BGM类、娱乐八卦类）
- ❌ 挂羊头卖狗肉进官方活动池（会被判定低质关联降权）
- ❌ 拉踩其他雪场/品牌
- ❌ **堆标签** —— 他的习惯是极简
