何时读本文件：确认轮检测到头像资产、用户要求头像出镜、头像/音色配对变化或进行嘴位标定时；无头像触发时不要读取。

### 口播头像(avatar 出镜,每单一问制)

数据根 `assets/avatar/` 有头像资产时,开工确认轮同轮带问「**这条要不要头像出镜**」(不新增轮次);无资产零问、全程不提头像。

用户答案由 Agent **代写当单 brand 工作副本**的 `avatar.enabled`(true=出镜/false=不出镜,与每单拷工作副本同先例;正本口径同品牌正本条款——只说「这条」落副本,「以后都出/不出镜」才写回品牌线正本);答「不出镜」本单不再追问(单内沉默)。

- **出镜形态**:右下角圆形头像+程序两层口型贴片(单张闭嘴底图,voice 包络驱动,Rust 预计算绝对时间关键帧写进 index.html 头像块,JS 零逻辑);`svf build` 在 check 前自动执行头像环节,手动刷新用 `svf avatar`;
- **浮窗节奏**:浮窗**首段口播起点前 0.4s 才淡入**(封面/开头静默期零浮窗——cover.png 取视频第 0 秒,发布海报不带卡通泡);结尾 CTA 帧起点自动退场(闭嘴+0.4s 淡出,CTA 口播变画外音,不与结尾真头像同框);
  - **自创结尾帧文件名/路径必须含 `cta` 字样才触发退场**——否则卡通浮窗会陪跑到片尾与结尾真头像同框;
- **头像-音色性别一致是硬规则(双向)**:男像配男声、女像配女声——男像配女声/女像配男声都闹笑话;出镜而 brand.voice 既有音色与头像性别不符时,确认轮带出**同性别候选**请用户拍板后写副本,**禁静默换声**(换音色=全量重录,计费影响同轮说明);
- **版式避让**:出镜的片正片帧内容须**避让右下头像安全区(约 220×220=直径 180px+呼吸余量)**——QC 量测会掩蔽浮窗足印,但被头像压住的内容同样量不到,避让靠设计;
- **头像浮窗归 svf 管**:Agent 不手改块内关键帧,**MUST NOT 手搭悬浮头像块**——手搭块吃不到标定副件与口型包络,页面里卡得住、成片也飞;build 渲染前对疑似手搭形态报 WARN 指路;
- **调嘴位**走图旁 `.calib.json` 标定副件,`svf avatar --calib` 标定页定稿——块内手调 `--mouth-*` 旧口径已废止,重跑即冲,细则见嘴位标定条款与模板 README 口播头像节。

字段三键见 `references/brand-fields.md`。

### 嘴位标定(标定权在用户)

口型贴片嘴位五值(中心 x/y+宽高 w/h+嘴色)缺省(x44/y47/w12/h7/#7d3f2f)系内置 v1 底图专属四轮定标,**自带头像几何不同即错位**(实案:嘴悬在脑门上一张一合)——用户自带图必标,标定权交用户不交 Agent。

**标定流程**:

1. 副件缺失即首次——运行 `svf avatar --calib --brand <b> --project <d>` 生成标定页(项目目录 `avatar-calib.html`,图像内嵌断网可开,零计费不碰 index.html),浏览器打开交给用户拖拽,收尾问句写死模板「**标定页已开浏览器,拖好嘴位粘给我**」;
2. 标定页下方定稿框**支持直接手改数值**(x/y/w/h/color——圈选不好用时手改,改完点页面别处生效),备注可写在 JSON 外(不进产物)——用户粘回的内容可能带备注,取 JSON 段原样转参即可;
3. 用户粘回的一行 JSON(`{"mouth":{...}}` 五值或 `{"lipsync":false}` 静态)**原样转参落盘**:

   ```bash
   svf avatar --calib-save '<json>' --brand <b> --project <d>
   ```

   Agent MUST NOT 手写副件文件——写错位置/写错形态渲染即断链;svf 同链解析源图+校验五值域+原子写,落点=源图侧 `<图名>.calib.json` 三级根解析位,非项目内拷贝位——换项目零重标;
4. **换图重标,多图各标各的**;build 报文 avatar 行会 WARN 提示未标定(缺省贴片),标定一次后自然消失。

**收图口径(用户自带头像入库时)**:

- 硬闸三项=图可解码/png/jpg/分辨率≥512(Agent 收图时核,不过闸退回重收);
- 推荐句=「微笑露牙、脸占满、嘴在画面竖向正中附近」;
- AI 生成时提示词模板=扁平插画风格、正面头肩、闭嘴微笑微露牙、1:1;
- **唯一明示禁项=张嘴图**(静默期定格穿帮,标定救不了)。

**责任边界**:已给明确要求用户不照做,效果不好我们不负责——软件没法干预用户的所有操作。**降级条款**:用户不拖/标定页打不开→写 `{"lipsync":false}` 副件出**静态浮窗单**(浮窗照出嘴不动,漂浮/淡入淡出保留),不禁用头像不拦交付;重标=覆盖副件再跑 avatar。
