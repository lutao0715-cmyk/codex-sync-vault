何时读本文件：任何出片、改稿或重新交付，在写项目文件或触发计费前；首次建项目、确认轮、写稿、时间轴和重跑阶段继续按本文顺序执行。

## 1. 出片工作流(核心协议)

### 新建项目(空目录从零起手)

- 目录契约与起手顺序见 `references/red-line-details.md` 的「新建项目骨架」节;
- **骨架从 `~/.svf/templates/` 整树拷贝**:index.html + 三帧骨架 + `assets/{fonts,vendor,img,audio}/` + package.json + README.md,字体与 gsap 已本地自包含,含默认底乐 `assets/audio/bgm-default.mp3`(Suno 生成真音乐,商用授权见模板 LICENSE-NOTES.md);
- 该目录不存在时**不做相对路径回退**——直接报人话「模板未安装,重跑安装器 `bash install.sh` 重建 ~/.svf/templates/」并按未安装时的自举条款处理;模板探测**禁 `..` 向上穿越的相对段**;
- 按模板 README 替换「」占位文案——禁凭空造帧,也不再从旧项目抄(纪律 22:骨架与配置件旧项目的一个都不许搬;用户品牌资产走白名单);
- brand.json 无 BGM 积累时直接引用模板默认资产 `"bgm": "assets/audio/bgm-default.mp3"`(用户有自己的品牌 BGM 时用用户的);
- **新用户首单的品牌落位**=新建品牌线(brands/<品牌>/)或显式询问品牌归属,禁默认借用任何现成品牌线路径;
- **新项目建在数据根的 `projects/` 下**——数据根位置读 `~/.svf/data-root` 记录文件(安装器写入),无记录时默认 `~/短视频工厂/`,已有项目的老用户沿用既有 projects/ 结构即可。

**Windows 宿主路径同构**:程序根/数据根记录在 `%USERPROFILE%\.svf\`,数据根默认 `%USERPROFILE%\短视频工厂\`,其余语义(projects/ 结构、模板拷贝、npm 向上查找)完全一致。

### 配音凭证(零凭证)

- 出片**无需任何凭证配置**——TTS 走自家配音网关(凭证只在服务端),装机即出片;
- 配音环节需联网:首次 build 断网会报「配音服务器暂时连不上」,联网重跑即好;`svf doctor` 的「网关连通」项断网时 WARN 属正常,不影响安装;
- 试用与拦报口径见**激活条款**;数据根内若有旧版遗留的 `.env.local`,新版已不读取、不删不影响,可自行清理。

### 首次出片(项目目录 + brand.json 已就绪)

1. **写/改 brand.json 前 MUST 读 `references/brand-fields.md`**,字段以该文档为准,禁止自造字段名;
2. **文案先过时长预算**(口径见 `references/red-lines.md`):字数上限 = `script.target_duration_sec`(缺省 75)× 5.5,按全部字符算(含英文与标点)——写完先运行 `svf script --check --brand <brand.json>`，超了先砍文案再合成；CLI 硬闸会在计费前拒绝超预算。
3. `svf build --brand <brand.json> --project <项目目录>` —— 首次 build 让 tts 跑完即可;
   - **新项目首次出片必须一条龙起步(红线):分步子命令仅限增量重跑**——分步绕 build 同时绕开 QC 闸与状态记账;
   - **禁止为通过 check 而预填估计时长**,否则 check/render/mix/cover 会按假时长白跑一趟,浪费一次完整渲染;
4. `svf probe --project <项目目录>` —— 拿每条配音的时长 JSON;
5. **暂停点(你的核心工作)**:
   - 各帧内容(标题/要点/构图)——**这一步只有你能做,CLI 不代劳**;
   - 时间轴数值两法任选:手填(按 probe JSON 的每条时长填 `<audio data-start/data-duration>`),或帧写完后 `svf timeline --apply` 一条命令排表写回(实测→排表→index 四类落点+帧内同步+自校验,参数见 `references/cli-reference.md`);
   - 首条配音 `data-start` 默认 **2.0s**(封面静默期,多单校准默认;用户明示过偏好时按用户偏好);
   - **片尾收尾口径:成片总时长=末条配音结束+0.5s~1s**(timeline 命令排表取 +0.5s 下沿,**收尾余量归末场景窗**——末场景时长=wav 实测+0.5,audio 声明保持实测;余量只加 root 不延场景窗=片尾黑屏,历史实弹),CTA 场不留无意义悬停(场景时长收到该口径内,时间轴改动按 gotcha(时间轴重排)处理);
6. 再跑 `svf build` —— 未变化的环节自动 cached,产出 `renders/video-vertical.mp4` + `cover.png`;
7. **交付形态默认**:成片之外默认同交**倍速版**(对外发布用,关系完播率;用户明示不要时跳过)——倍速值=确认轮拍板口径(数据根 profile 记忆,缺省 1.15x);
   - 倍速件一律出自 **`svf speedup --project <项目目录>`**(缺省读 profile;音调不变,母带只读,内建响度复测+越带自动校正),**禁止手搓 ffmpeg 变速命令**;
   - 产物 `renders/video-vertical-<倍速>x.mp4`(如 `video-vertical-1.15x.mp4`)。

### 改稿重跑

- 只改帧文件(compositions/**):直接 `svf build`,级联只重跑 check/render/mix/cover,不重花 TTS 的钱;
- 改了文案:**段级计费**——CLI 逐段对账只重打漂移段(报文 K/N):**先向用户说明计费影响(只计 K 条),确认后带 `SVF_FORCE_TTS=1`** 跑 `svf build`(force=只重打漂移段,未动段 wav 逐字节复用、时长零漂)→ `svf timeline --apply` 重排时间轴(或先 dry-run 看补丁)→ 再跑 `svf build`;
  - 换音色=全量重录(音色变更);全量重打出口=删 assets/voice/ 下 wav(段表随 wav 一并失效);
- 只改 bgm_volume:只重跑 mix/cover。

### 失败续跑

任何环节失败,build 退出 1 并点名失败环节;修好后**零参数**重跑 `svf build`,自动从失败环节续起。已成功环节的状态在 `.factory/state.json`。

> gotcha(时间轴重排):改完文案必须重排时间轴——重打段(哪怕 1 条)新 wav 时长有零点几秒漂移,按旧时长必错;tts 双层指纹:批指纹(整份文案)判环节是否重跑,段指纹表 `assets/voice/.segments.json`(与 wav 同目录同生命周期)判哪些段重打——一字未动整环节 cached;改稿只重打漂移段;全命中=零计费直返。
>
> 混音前有**时长校验闸**:wav 实测 vs index 声明偏差 >0.1s 直接拒混——被拦说明时间轴没跟上新 wav,跑 `svf timeline --apply` 一条命令重排(覆盖场景 data-duration / root 总时长 / gsap tl 锚 / 帧内 duration 四处),不是 bug。
>
> gotcha(口播头像):口型跟 **voice 段**不跟 mix 成片——改稿重打/时间轴重排后旧关键帧即失真(新 wav 时长、新 data-start 都会让嘴形错拍)。`svf build` 会在 check 前自动重刷 avatar(新关键帧随新时间轴),无需单独跑;只有绕开 build 分步走 check/render 时,MUST 先手动 `svf avatar --brand <brand> --project <项目>` 再渲染。
>
> 浮窗淡入/退场节奏与 `cta` 字样触发条件见口播头像条款。
>
> gotcha(嘴位标定):自带头像必标、副件不手写——完整标定流程与收图口径见嘴位标定条款。
>
> gotcha(批量数值替换防呆,历史实案):一次改多帧多个数值(位移/字号/top 坐标)MUST 用**映射表一次遍历**或按替换值**从大到小**排序执行,禁链式 sed 顺序替换——前一条的替换产物会被后一条再命中(320→520 后又被 520→720 命中,01/06 帧重叠手工修复实案);替换完 grep 复核无二次命中再进渲染。
>
> gotcha:macOS 上骨架/模板树整目录拷贝用 `ditto <src> <dst>`(cp -R 丢权限与扩展属性)。
>
> gotcha:ffmpeg 抽帧循环**先拼好输出文件名清单再循环**——循环内现拼文件名有引号/变量展开时机坑。
### 开工确认轮

新选题开工时,**角度、视觉风格、结尾头像、背景图四项合并为一轮问完**(背景图一问已列入正式清单:此前只写在正文,真单被漏掉过一次);拍板后才写稿动工。

1. **角度/视觉风格**:风格候选=沿用品牌既有风/其他已知风/用户给参考图(风格轮换规则见第 7 条);
2. **结尾头像**:按 brand.json `cta_avatar`——**素材在位=零问**(在位=直接采用品牌线正本,不问用户),仅 true 且缺素材时现场收图入库;品牌线既有可复用资产(bgm/头像/字体)同口径:**在位即用零问,缺失才问,问时给出品牌线正本路径**;
3. **氛围背景**(项目级问一次,已提入确认轮正式清单):以**四项之一**的身份列出(不得只当正文附注)「要不要给这条加一张背景图?想加就发一张本地 PNG/JPG(会压暗衬前景,是能看清的照片),不加就按现在这样」(不新增轮次);
   - 同一项目问过一次即不再问(答不加/已启用背景/后续改稿单都沉默);背景图永远只来自用户——AI 不搜图、不生成、不推荐(细则见背景图条款);
4. **倍速=记忆式提问**:
   - 数据根 `profile.json` 有有效 `delivery.speed_factor` 时,同轮加一句「**还是老规矩 X 倍速吗**」记忆确认(用户一个字拍板,不新增轮次);
   - 无偏好或文件损坏时问一个**可跳过的轻量问项**——「倍速有偏好吗?不说就按默认 1.15x」(同轮带出、不新增轮次,给口头表态一个明示出口;损坏只在汇报提一句);
   - **用户任一倍速类口头表态=当单生效+立即代写 profile**:写/改**数据根 profile.json** 的 `delivery.speed_factor` 字段为表态值(保留其余字段;合法域 0.5~2.0),写失败不拦本单交付、汇报中说明并补写;
   - 落位=程序根 `~/.svf/data-root` 记录文件所载的绝对路径,典型 `~/短视频工厂/profile.json`;**严禁写进 `~/.svf/` 程序根**——写错位置 CLI 读不到,倍速会静默回退默认值;
5. **头像出镜一问**(有资产才问):数据根 `assets/avatar/` 有头像资产时附一句「这条要不要头像出镜」,答案代写当单工作副本 `avatar.enabled`,答否单内沉默;出镜而与 brand.voice 性别冲突时同轮带同性别音色候选拍板(禁静默换声,细则见口播头像条款);
6. **人味素材一问**:同轮附一句「这个话题/工具你自己上手过吗?一个细节或一句看法就行」——采集、体验库带出与降级链细则见人味三件条款(句式与追问模板见 `references/content-flavor.md`);
7. **风格轮换**:连续 2 单同视觉风格时,下一单开工确认轮 MUST 主动提新风格候选(不能只给「沿用既有风」;用户可拍板继续沿用,但新候选必须给出)——审美疲劳实防(候选配色可读 `references/palette-catalog.md` 按选题题材供色,8 组静态参考;配色=多样性弹药非频道身份,零新问项零强制轮换);
8. **上屏文案候选制**:只对新创关键文案给候选——封面主标题、封面副标题、CTA 句,每处 2-3 个候选一轮拍板,**不自创终稿**;
   - 口播稿确认后的衍生浓缩(帧标题、帧内要点行)直接自决,**不逐条问**(拍板疲劳实案),自决项列入交付汇报「计划承诺对齐」供事后抽验;
   - 计划承诺对齐=终稿交付前对照自己的计划书关键承诺(标题/卖点/结构)逐项核对,漂移要么改回要么说明;
9. **音色**:见音色条款的**音色沉默禁令(正本)**——确认轮不因音色单列问项,头像配对冲突时的同性别候选带出是唯一的音色出口。

### 新样式预览拍板(设计确认闸)

用户拍板**新开样式**或对既有样式**骨架级改款**(动网格/配色系统/字体系统;换文案/数字/微调间距不算)时,MUST 先出单文件 `design-preview.html` 三帧预览(封面/信息帧骨架/CTA,用项目真实字体包,零渲染零计费)并在浏览器打开请用户拍板,**过稿前不得写全量正式帧**。

收尾问句写死模板「样式预览已开浏览器,过不过?过了我写 N 张正式帧」(自觉型条款防漏做)。

- 存量样式复用=已验收资产,**零预览零新增问项**(同在位零问口径);
- 预览确认的只是**风格方向**(配色/字体/构图语言),逐帧合规(重心/封面锚/安全区/压叠)仍归 framecheck+QC,**预览不替代闸**;
- 预览稿随项目目录留档当该样式参照件(不进 templates 母版)。

### 人味三件(口播稿必覆盖)

第一人称真实体验 + 个人观点 + 结尾开放式互动问句(问句由 CTA 三段式承载)。

- **素材三姿态降级链**:**体验型**(真上手,讲一个具体细节)> **判断型**(未上手但有看法,agent 代拟候选供选)> **类比型**(用同域实战接话,经历为真、措辞可代拟);
- **体验细节禁代拟(红字级)**——agent 只能采集与追问,伪造人味=伪造真实性,平台识别与账号风险远大于流量收益;
- **素材双层**:体验库同话题优先带出 + 确认轮人味一问;两层皆空从判断型起步;
  - 体验库(数据根 profile.json `flavor` 节)有同话题条目时改**记忆确认式**带出(「上次你说过:…还用这条吗」);
  - 未答或「没用过」即降级,不追问不阻塞;判断/类比候选句同轮供选(2-3 条),选定句当单回写 `flavor` 节(写失败不拦交付,汇报说明);
- **选题双源**:向用户供选题候选时,**实操型**(用户一手产出,天然自带真实体验)占默认推荐位——「泛资讯满大街,一手实操是稀缺品」;用户指定资讯型(外部文章)时人味三件覆盖 MUST NOT 省略(纯转述正是运营点名的画像)。

句式弹药库(三姿态例句/桥句/问句库/四诉求指令/置顶评论钩子/违禁清单)见 `references/content-flavor.md`,写口播稿与 CTA 时必读。

## 2. 命令速览

| 命令 | 职责 | 备注 |
|---|---|---|
| `svf build --brand <b> --project <d>` | 一条龙:tts→check→render→mix→cover | 主入口;失败后零参数续跑 |
| `svf qc --project <d> [--video <mp4>]` | 对已成片独立复跑质检(白屏/墨迹/重心/时间轴/响度) | 不写 state、零网络零计费;复核/终检用 |
| `svf framecheck --project <d>` | 渲染前帧量测判读独立复跑(压叠/溢出/孤字候选,定格态量 DOM 几何) | build 在 render 前已自动挂闸;复跑看 warning 全文用;不写 state、零计费 |
| `svf timeline --project <d> [--apply]` | 时间轴重排一条龙:wav 实测→排表→补丁 JSON 预览;`--apply` 写回+自校验 | 换音色/改稿后重排用,替代手改四处;dry-run 即全量校验,未命中零写入 |
| `svf avatar --brand <b> --project <d> [--calib \| --calib-save <json>]` | 口播头像:voice 包络→口型关键帧,幂等写回 index.html 头像块+拷图进项目;`--calib`=只生成嘴位标定页 avatar-calib.html(不碰 index.html);`--calib-save '<json>'`=把定稿 JSON 落盘到源图旁副件(与 --calib 互斥) | 零计费;build 在 check 前自动挂,分步改稿后手动刷新用;标定页交用户拖拽定稿,粘回后 Agent 转参 --calib-save 落盘(不手写副件) |
| `svf background --project <d> ...` | 当前项目的一张静态氛围背景图:预览、应用、改出现范围或撤销 | **只在用户主动给图或明确要求背景时**使用;先预览、用户确认后才应用;完整命令见 references/cli-reference.md |
| `svf speedup --project <d> [--factor X]` | 对既有成片整体变速出倍速件(音调不变,内建响度复测) | 倍速缺省=数据根 profile 口径(再缺省 1.15);母带只读;替代手搓 ffmpeg |
| `svf clean --project <d>` | 清可再生中间产物 | 不动 renders 历史与 cover.png;clean 后重建 tts 重打须 `SVF_FORCE_TTS=1` |
| `svf activate '<码>'` / `svf activate --status` | 激活码激活:解析→服务器登记→license 落盘;`--status`=授权状态只读自诊(零网络零计费零写盘) | **用户主动粘码或撞拦报才跑**(协议见下方激活条款);授权状态不明或激活后仍被试用拦时先跑 `--status` 照文转述;stdout 人话照文转述;激活唯一正门 |
| `svf tts / probe / check / render / mix / cover` | 单环节执行 | 参数细节见 references/cli-reference.md |
| `svf --version` | 版本号 | 与发布 tag 一致 |

契约:stdout 只出机器可读 JSON(可管道给 jq);进度与错误全走 stderr(`[svf]` 前缀);退出码 0/1;全参数化、无交互。
