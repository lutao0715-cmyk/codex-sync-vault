何时读本文件：用户主动粘贴激活码，或 svf 报出试用/授权拦截时；未触发这两种情况不要读取或主动引导激活。

### 激活(用户粘码时才发生,拦报双源)

**总纲:激活链路的一切报文(本地 stdout / 拦报 / 服务端 error)一律照文转述给用户:不加工不代付不绕闸,不猜测;本地数字与服务端对不上时以服务端原文为准。**

- **试用**:免费试用=5 条新视频(改稿重跑不占额;本地闸快失败,服务端同口径镜像双保险),用完会在 tts 计费前被人话拦下;
- **触发点**:激活交互只出现在两触发点——**用户主动粘激活码**或**撞试用拦报**;不到触发点全程不提激活(安装收尾与日常出片零激活引导);
- **用户粘码**:码**原样作参**运行 `svf activate '<码>'`(全流程自动:解析→激活服务器→license 落盘),把 stdout 人话照文转述(成功=档期与解锁说明;失败=原文转述);
- **撞拦报**:照文转述拦报原文,引导只一句「想要一直用,找推广员拿激活码,把码发给我即可;也可在线购买:https://svf.atomcreate.cn/buy」(试用满与授权到期两类拦报均自带购买入口);
- **服务端拦报两场景**:①试用满(403「免费试用已用完」,服务端 error 原文进 stderr)→引导拿码;②激活到期(403 续费引导,报错自带「联系推广员」)——两报文都是服务端算的账;
- **MUST NOT 三禁(收权口径)**:①手写 license 文件(伪造授权,形态错渲染即断链);②手搓 HTTP 直连激活端点(绕过解析与验签,必失败);③请用户提供开发者侧信息(私钥/服务器配置类——用户没有也不该有);
- **换机/到期类报错**:照文转述即可,报错自带「联系推广员」指引;
- **授权异常自诊**:激活成功后仍被试用拦,或授权状态不明(报文与预期不符)时,先跑 `svf activate --status`(只读零计费零写盘)把 stdout 照文转述——unreadable 态=本机读不出硬件标识的环境问题线索,按报文引导联系推广员;不手改任何授权相关文件。
