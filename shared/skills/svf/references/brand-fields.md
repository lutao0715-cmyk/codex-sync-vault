何时读本文件：新建或修改 `brand.json`，或需要理解 bgm/voice/script 字段语义时。配音零凭证(走网关)，旧版凭证字段说明见文件尾部。

# brand.json 字段说明

## 结构

```json
{
  "id": "your-brand",        // 品牌标识(kebab-case)
  "name": "<品牌主>",           // 品牌显示名
  "type": "...",             // 品牌类型
  "voice": { "voice_id": "..." },  // 豆包音色 id;可从 references/voice-catalog.md 中文名选定后代入,渠道/用户自备值仍直写
  "bgm": "brands/<品牌>/assets/bgm.mp3",  // BGM 路径;推荐数据根相对写法(解析顺序=先项目目录后数据根),无自有 BGM 时引用模板默认 assets/audio/bgm-default.mp3
  "cta_avatar": false,       // 可选,缺省 false=结尾帧三件套(无头像位);true 时必须有真实头像素材 brands/<品牌>/assets/avatar.png——素材在位=零问(在位直接用,不问用户),仅缺图才在开工确认轮向用户收
  "avatar": {"enabled": true, "image": "assets/avatar/avatar.png", "size": 180},  // 可选,口播头像:整字段缺省=能力关(既有项目零影响);enabled=true=右下浮窗出镜,false=显式关(摘除既有头像块);image=头像图路径(项目→brand 根→数据根三级解析,推荐数据根 assets/avatar/);size=直径像素 16~2000(缺省 180)。启用判定=每单一问制(见 `references/avatar.md`),答案代写当单工作副本;嘴位五值不入 brand——属图不属品牌,走源图旁 `<图名>.calib.json` 标定副件(`svf avatar --calib` 标定页定稿,见 `references/avatar.md`)
  "cta": {
    "text": "评论区聊聊",          // 可选,行动指令词(四诉求选一:互动/涨粉/数据/转化,≤10字);旧项目值照读不迁移,但旧值含个人 IP 名或「扣 1」类废止句式时 MUST 在开工确认轮按四诉求重填(候选拍板,正本不手改)——IP 名禁令无条件优先、不设豁免出口;禁个人 IP 名与「扣 1」类利益诱导(已废止)
    "hook": "能跑通吗",            // 可选,开放问句关键词(结尾帧胶囊第二枚用,≤15字问句的关键词);缺省不带
    "signature": null              // 可选,署名文字;null/缺省 = 不署名
  },
  "script": {
    "angle": "...",          // 内容角度:描述核心事件,不写融资/背景角度
    "target_duration_sec": 75,   // 可选,成片目标时长(秒),缺省 75;字数上限 = 该值 × 5.5
    "lines": [
      { "frame": 1, "text": "..." }   // 逐条文案,frame 为整数序号
    ]
  }
}
```

## 关键约定

- `script.lines` 逐条生成 `assets/voice/<frame 至少两位补零>.wav`;tts 双层指纹:**批指纹**(整份文案)判环节是否重跑,**段指纹**(`assets/voice/.segments.json` 段表,与 wav 同目录同生命周期——删 wav=清段表)逐段记 frame+text+voice+speed——一字未动整环节 cached;改稿=**只重打漂移段**(K/N 报文,其余 wav 逐字节复用);换音色=全量重录;全命中=零计费直返。
- **文案先过时长预算再合成**:字数上限 = `script.target_duration_sec`(缺省 75)× 5.5(预算口径见 `references/red-lines.md`);超预算先砍文案,合成后返工 = 已计费字数全部作废;真要长视频就上调 `target_duration_sec`,闸门随配置放行。
- **最后一行通常是关注 CTA 文案:只放音频,不单独建帧**——视觉 CTA 由结尾帧承担。
- `voice.voice_id` 零凭证:出片不再需要任何凭证配置(配音走联网网关,凭证只在服务端)。缺省不写 voice 块时用内置默认音色(恒可用);写入的 voice_id 须在**服务端音色目录**内(=音色目录 36 条全量+默认音色)——目录外值会在合成时撞「音色未收录」拦截,按报错重选或向发放渠道反馈补录。具体默认值以 `svf tts --help` 与 specs 为准。`references/voice-catalog.md` 是 voice_id 的**中文名翻译层**(36 条精选,换音色/报错回退时读它报中文候选),不改变本字段语义——voice_id 真源=服务端音色目录与 brand.json,用户/渠道自备值照写(目录内即生效)。
- `bgm` 与 `bgm_volume` 只影响 mix 环节;改它们只重跑 mix/cover。**`bgm_volume` 合理区间 0.1~0.3(缺省 0.18),超出须用户明示**——真音乐底乐配高了会盖人声(bgm_volume=1.0 嗡鸣独奏事故实案)。**`bgm` 未配置(缺失/null/空)→ 静音兜底+警告;已配置但项目目录/数据根两处都找不到文件 → 拒混硬失败(退出 1,报错列出全部尝试路径)**——配置断裂是错误不是选择(build 在计费前也会前置拦截);源时长不足(短于 15s 偏移+片长)→ svf mix 自动无缝循环补齐铺满全片并告警(不拒混)。
- **bgm 路径两种写法的解析差异**(历史回归根治):推荐数据根相对写法 `brands/<品牌>/assets/bgm.mp3`——任何项目位置都能命中同一份品牌底乐;项目相对写法(`assets/audio/bgm.mp3`)只在**该项目内真的放了这份文件**时才命中,否则落数据根再 miss 就静音兜底。换写法前先确认文件实际所在。
- **BGM 自换协议(用户主动换底乐)**:操作四步、正本口径、风格匹配交互与版权自负一句见 `references/brand-voice-bgm.md`;本文件不重述,只留**字段面事实**:`bgm` 写数据根相对路径 `brands/<品牌>/assets/<文件名>`(品牌资产位,跨项目复用),改后只重跑 mix/cover;音量争议以试听为准。
- `cta_avatar: true` 时结尾帧加圆形头像位(素材=`brands/<品牌>/assets/avatar.png`);**素材在位=零问**(历史实案:头像在位仍问用户,被点破后自愈)——在位直接采用正本,仅缺素材才收图,问时给出品牌线正本路径;**占位人形图不存在也不许用示意图顶替**。缺省 false 走三件套版式。品牌线既有可复用资产(bgm/头像/字体)同口径:在位即用零问,缺失才问。
- `avatar`(口播头像)与 `cta_avatar`(结尾帧头像位)是两套独立能力:前者是全程右下浮窗+程序两层口型贴片(包络驱动),后者是结尾帧静态圆形头像位。**两套头像资产不共文件**——口播头像拷入 `assets/img/avatar-talk.png`,结尾帧专用 `assets/img/avatar.png`(验收抓到撞名互覆,已分道)。
- `avatar` 只影响 check/render 指纹面(写回 index.html 头像块+拷图进项目),tts/mix 指纹零影响——改 avatar 只重渲染,不重打不重混。启用而图在三级根全 miss=build 在零计费环节拦下(exit 1 人话,列全部尝试路径);`enabled:false`=显式关(摘除既有头像块);字段整删=零触碰。启用判定=**每单一问制**(数据根 `assets/avatar/` 有头像资产时开工确认轮问一次,答案代写当单工作副本,配对规则见 `references/avatar.md`)。头像图建议:单张闭嘴正脸、≥440×440 PNG、浅色底(即圆盘底盘,无需透明抠图)。
- `cta` 字段**只被技能/Agent 读取**(决定结尾帧文案与署名),CLI 不读——改 cta 不需要重跑任何 svf 环节,只需改视觉帧后重渲染。

## 品牌正本与工作副本

- **纪律正本在 `references/brand-voice-bgm.md`**(拷贝副本/单内改写只落副本/三类写回带披露),本文件不重述;本节只留**字段面事实与出处**:
- 两个文件的角色:品牌线 `brands/<品牌>/brand.json` = 正本,项目内那份 = 当单工作副本(`svf build --brand` 指向副本);品牌线正本单内零污染。
- 三个历史实案(条款因它们成文):正本当每单工作文件=品牌口径漂移无痕;同模型两态=正本卫兵是自觉不是条款;换音色披露与回退出口全履行、唯触发面宽。
- **宿主记忆注记**:Agent 宿主侧自发的品牌口径记忆不禁止,但 brand.json 正本为品牌口径**唯一真源**——冲突时以正本为准执行,并向用户对齐差异后更新记忆。

## 凭证(已废除,零凭证出片)

TTS 走自家配音网关,**出片无需任何凭证配置**——装机即出片,凭证只在服务端。旧版的三级查找(环境变量 > 项目 `.env.local` > brand.json)随之废止:数据根内若有旧版遗留的 `.env.local`,新版已不读取、不删不影响,可自行清理。**凭证值严禁写进技能包、日志或任何对话输出**的纪律不变。
