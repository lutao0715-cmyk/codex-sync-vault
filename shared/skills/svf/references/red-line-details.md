# 红线细则:安全区 / 封面 / CTA / 时间轴 / 样式 / 项目骨架

## 1. 四边安全区(1080×1920 硬规范)

| 边 | 最小边距 | 写法 |
|---|---|---|
| 左 | 160px | 内容统一 `left: 160px; width: 760px` |
| 右 | 160px | 同上(右侧是平台按钮列) |
| 上 | 180px | 最上方元素 `top` ≥ 180 |
| 下 | 360px | 最下方元素底边 ≤ 1560(即 `bottom` ≥ 360) |

**品牌锚条件化(「默认单一品牌锚」形态废止)**:**默认零品牌锚**——信息帧不挂常驻品牌元素。历史实案:每帧 `#brand` 圆点+账号名上屏被用户打回——账号目录名=内容赛道分组,上屏如自贴名条;与 WorkBuddy 单页眉「WORKBUDDY SKILL KIT」打回(信息稀碎、无信息量)同族=品牌噪音。品牌方明确要求携带时才加:内容=**栏目/主题标签类**(如「AI 实战」),顶左角 `top:180` 单锚;**MUST NOT 上屏账号名/个人名**(与 CTA 的 IP 名禁令同源,抽检按全帧扫描账号名核对,不限于 CTA 帧)。品牌方明确要求页眉时才用下面骨架(写新帧直接抄,颜色随当套模板调,**位置数值不许动**):

```css
#fx-mast { position: absolute; top: 180px; left: 160px; width: 760px; }
#fx-mast .rule-t { height: 6px; background: #17140f; }
#fx-mast .row { display: flex; justify-content: space-between; align-items: baseline; padding: 20px 0 16px; }
#fx-mast .rule-b { height: 2px; background: #17140f; }
#fx-foot { position: absolute; bottom: 360px; left: 160px; width: 760px; }
#fx-foot .rule { height: 2px; background: rgba(23,20,15,0.6); }
#fx-foot .row { display: flex; justify-content: space-between; padding-top: 14px; }
```

行宽纪律(通用估算公式见 `references/red-lines.md`;本文件补四条特有细则):中英混排标题必须留换行余量——长词落到行尾会把次行挤成孤字或贴边(WorkBuddy 混排实案:3 行折行后底边距只剩 13px);**全屏居中构图帧按画布 1080px 计同一口径**(内容区 760px 的判据见 `references/red-lines.md`)。

- **连续英文长词按 ~0.55em/字符估宽**(产品名如 WorkBuddy:9 字符 ≈ 5em,远比汉字宽)。
- **孤字铁律**:断行后次行只剩 1-2 字 = 收字号/收字距把整行收回单行,不放孤字——宁可字小,不许孤字断行(历史高发问题)。
- **居中胶囊/徽章**:别用 `left:50% + translateX(-50%)` 单独定位——有效内容宽只剩右半屏 540px,文字稍宽即内部折行;用全宽容器(`left:160px;width:760px;text-align:center`)+ `inline-block` 胶囊。
- **胶囊行注意总宽**:flex 不换行 + `justify-content:center` 的容器,子项总宽超容器时会被对称挤到容器外两侧(实测徽章行溢出到 x=103~975 被墨迹扫描拦截)。

**四边管所有墨迹(严格口径)**:插画/mockup 类元素(浏览器窗口、终端面板等)同样受安全区约束——不许 `left:120px; width:840px` 这类宽插画,统一收进 160~920。

**块间距纪律(历史实案立;判定升级)**:垂直堆叠的块(卡列与注、注与底边)写完即对账——上块底边(实际高,不是 CSS 里的 top)与下块 `top` 的间距:压叠(负值)**MUST 修**后才可交付,0~16px 记候选调整,≥16px 合格。

- **为什么靠闸不靠算**:卡高随字号/行数浮动,CSS 静态算不准;check 的 layout lint 有容差带,压叠在带内漏网过闸不单独放行(实案:05 帧 note `top:1330` vs 卡底 1351,压叠 21px 漏网,用户目检兜住,framecheck 闸即为此立;同单 03 帧 16px 间距为合格样例)。
- **判定依据两道**=渲染前 framecheck 闸第一道(build 在 render 前自动量测 DOM 几何,压叠 violation 必拦 exit 1)+ 渲染后抽帧复核——降级场景(`qc.frame_check.status="skipped"`)抽帧回到一级。
- **盒级口径**:闸与红线都按渲染实测盒位判,墨迹轻触不算豁免依据——旧片盒压而墨迹仅轻触的会被闸捞出属闸在工作。
- **修法**:优先下移下块或收上块高(收字号/收 padding),不动安全区坐标。

**帧内必写全局 reset**:每个帧文件 `<style>` 首行写 `* { margin: 0; padding: 0; box-sizing: border-box; }`——index.html 的全局 reset 进不了帧模板(帧是独立文档)。hyperframes 0.7.109 渲染器已对 box-sizing 上游归一化(三路实测),但 h/p 等默认 margin/padding 仍靠这行兜底,写了零成本。

**帧内禁完整 URL/域名**:任何帧与封面不出现 `https://...`、`xxx.com` 等链接字样(平台广告误判);平台名字样允许(「GitHub」「小红书」OK)。**同口径覆盖资源引用**:gsap 等脚本只允许项目内本地文件(`assets/vendor/gsap.min.js`,模板自带),MUST NOT 引 CDN——渲染零外网依赖,网络波动不炸渲染。**该红线已代码化**:`svf check`(含 build 编排)前置扫描全部 html 的 src/href 与 CSS url(),http(s)/协议相对 `//` 引用直接拒跑并列出文件行号;存量项目重跑被拦 = 预期行为,修法是骨架本地化,不是绕闸。

墨迹四边测量已由 build 内置:成片级 `qc.pixel_scan` 逐场景中段抽帧、梯度墨迹、越界硬拦(violations → 退出 1),孤字/折行候选进 warnings(必须逐条人工过目并在汇报中回应)。改帧时的快速自查仍可手动抽帧测量,不必等整条 build。

## 2. 封面首帧

- 平台默认封面 = 视频第 0 帧:必须完整显示品牌/事件大名、核心标题、必要视觉元素。
- 封面元素 CSS 直接 `opacity: 1`,不能动画淡入;入场动画用 GSAP `fromTo(..., { opacity: 0, ... }, { ..., immediateRender: false })`,确保 t=0 显示 CSS 初始态。
- 封面导出为 `cover.png`(`svf cover`)。
- 若项目有独立 `00-cover.html`(封面专用帧):正片帧加/改视觉元素(产品图标、头像等)必须**同步改 00-cover**,否则开屏封面漏元素(有实测踩坑记录)。
- **信息预算**(用户反馈轮立):封面 = **一个视觉钩子 + 最多一个数字背书 + 可选一行弱化辅助**(灰色小字级);同一数字全封面只出现一次;机制/数据详情(如 22×21×58)留正片帧讲。**自检:0.5 秒内说得出这条视频讲什么**。
  - **钩子按人群分支**:受众含未入门小白 → **痛点共鸣问句做主标题**(工具名对小白是陌生词,抓不到人);行业大事件/业内受众 → **主体名大字**;工具/产品热点认知期 → **主体名进封面主标大字,即使受众含小白**(第三支实案:热点期的主体名本身就是钩子、正在被全网搜索——封面与 CTA 只提场景不提主体名 = 白瞎热点;WorkBuddy 实案:封面「装 4 个 Skill」CTA「搞定办公场景」均无主体名,两轮打回)。
  - **计数口径** = 独立信息点:钩子的视觉佐证(如三张同款页面缩略图佐证「全都长一个样」)归钩子组,不算新信息组。
  - 实例:hallmark v1 封面 7 组信息+22k 出现两次被否;v2 砍成问句钩子+22K 徽章+缩略图佐证通过两层复核。
- **对外语言过滤(适用所有帧与封面)**:上屏文字以观众视角自检——内部策划语言(篇章名/排期名、目标人群定位、引流/漏斗术语、讨论中的分析框架词)禁入画面;允许的是给观众导航的段落标签(常见误区/回本公式/关键结论)与合规免责标注(「举例测算」)。判据:这块字对观众的作用说不出来 = 删。实例:ai-hardware-roi 封面 kicker「算账篇」(内部排期名)被用户打回,删除后产品图上移补齐构图;同片正片段落标签保留。
- **封面文字锚绝对带**:封面是机器测量豁免帧(全幅背景使墨迹 bbox 失效),**骨架默认坐标是封面唯一防线**;整帧重写(新风格常见)时,主标/副标等上屏文字锚 MUST 落在 00-cover 骨架默认锚 **440/670/785/930/1120 的 ±80px 带内**——「勿动」注释对整帧重写不设防,绝对带是可 grep 核对的硬口径(历史实案:主/副标重排至 1110/1310,重心 ~1230 偏离定标 ~290px)。

## 3. 结尾 CTA(品牌可配置,口播三段式+胶囊四诉求)

- 固定结构(**结尾两帧一组,分工反转后定稿**)——口播-视觉对齐=桥句落铺垫帧时段、问句与行动指令同落末帧时段(桥句属收束、问句属引导,分页才不打架);署名条可选,以 brand.json `cta` 配置为准;收束桥句帧按其构图形态适用定标口径(普通信息帧不豁免,全屏居中构图同封底豁免)。
  - **倒数第二帧 = 收束桥句帧**:承载三段式桥句的视觉重心,与承接/收尾内容(方案就绪类承接句、定位),铺到引导口即止,**不带问句**(旧拆法「桥句+问句同落铺垫帧」已废止)。
  - **最后一帧 = 引导帧**:开放式问句 + 圆形头像 + 红色胶囊 CTA + 一行评论区引导;附加元素仅一行弱化副条与可选署名条,**MUST NOT 塞定位大字/承接句/kicker 类内容块**(「引导页夹内容、完事儿才引导」即反模式,用户三次澄清定稿)。
  - 问句仍落铺垫帧(旧拆法)= 红旗清单项。
- 头像:`assets/img/avatar-circle.png`,圆形裁切 + 主题色边框 + 硬阴影,放在胶囊上方居中。
- CTA 口播(配音末行)= **三段式**:桥句 + 开放式问句 + 四诉求行动指令——定义、字数上限、缺省诉求映射见 `references/red-lines.md`;句式库与整句样例矩阵见 `references/content-flavor.md`。本文件只管**视觉落位与配置读取**(上方落帧分工 + 下方头像/胶囊/署名条)。
- 胶囊文案:读 brand.json `cta.text`(放**指令词**)与 `cta.hook`(放**问句关键词**,可选)——分开放,不塞长句;旧值照读不迁移,**但旧值含个人 IP 名(「关注XX哥」类真实人名)或「扣 1」类废止句式时,IP 名禁令无条件优先:MUST 在开工确认轮按四诉求重填(候选拍板,品牌正本不手改、写回走既有披露),不设豁免出口**(已分发多用户且持续,别人不叫这名,个人 IP 名对分发产品无条件不成立);新单按四诉求重填。**「扣 1」类利益诱导句式废止**(抖音运营反馈点名删除——选优建议级,相关视频均过审可播);只允许四诉求指令与「关注我」系轻表述,禁止「关注XX哥」等个人 IP 名(平台误判跨平台导流限流,两次实测确认)。
- 署名:读 brand.json `cta.signature`,缺省为空(不署名)。
- CTA 必须有配音,视觉弹出与配音起点同步;配音结尾与 `cta` 字段内容(指令词/问句关键词)一致。
- 禁止停在无动作的信息页上。
- **IP 名禁令覆盖全帧与封面**:不只 CTA 文案——任何帧内不出现个人 IP 名、品牌签名、日期底栏等水印式元素(同样触发平台导流/营销误判)。
- **引流人群定位**(skill/工具/AI 技巧类选题):此类视频是报课引流漏斗,CTA 钩「没入门想学入门」人群,不钩已入门进阶人群——钩子落位=**桥句与开放式问句,问句问小白想要的结果**:✅「给你,你先拿它做漂亮的界面?」;❌「想让 AI 做的页面不再撞脸?」(进阶诉求,只有已入门者共鸣)。结尾整体仍为三段式(不再有「想学习如何用 AI+主题动作,关注我扣 1」句式)。结尾帧副条同步零基础定位(如「零基础入门,持续更新」)。视觉胶囊仍按 `cta` 字段(指令词与问句关键词分开放)。非 skill 类选题不适用本条,仍走三段式通用句式与 `cta` 字段缺省。
- **自定 CTA 口径**(历史实案):配音末句为自定三段式时,brand.json `cta.text` MUST 写实际指令词、`cta.hook` 写问句关键词(不留缺省);结尾帧胶囊按此渲染——**配音里没有的词不渲染对应胶囊**,否则有字无音(画面承诺了一个动作,配音却没交代)。

## 4. index.html 时间轴约定

- 每个场景是 `<div class="scene">`,带 `data-composition-src`;每场景配一条 `<audio>`,放在 `data-track-index="10"`。
- **track-index 错开约定**:音轨固定占用 `10`;场景 div 的 `data-track-index` 用 0 起连续序号,**帧数 ≥ 10 时场景序号必须跳过 10**(11 帧项目曾发生场景占用 10 与音轨冲突,被 check 拦下)。
- 场景 `data-start` = 上一条配音结束时间(以 `svf probe` 输出为准)。
- 场景切换 0.5s 叠化:GSAP 在 `scene_start` 处同时触发上一场景淡出与下一场景淡入。
- 根 `#root` 的 `data-duration` = 总时长;最后加一句锚点动画:`tl.to({}, { duration: 总时长 }, 0);`。

## 5. 样式基线(终端代码风)

- 背景 `#0d1117`,面板 `#161b22`,边框 `#30363d`;
- 主文字 `#e6edf3`,弱化 `#8b949e`;
- 绿色 `#3fb950`,青色 `#39c5cf`,琥珀 `#d29922`,红色 `#f85149`;
- 等宽字体优先用 `JetBrains Mono`,中文标题优先用 `Noto Sans SC 700`;字体从项目 `assets/fonts/` 或本地已安装字体加载,**不是渲染器内置**。若本地缺失会回退系统字体,导致跨机器视觉不一致;新环境首次出片 MUST 在汇报中注明字体加载状态。
- scanline 纹理:`repeating-linear-gradient(...)`。
- **图标工艺钦定**:风格需要图标而模板不带图标资产时,按**内联 stroke SVG 配方**现写——`viewBox="0 0 24 24"`、`fill:none`、白描边(随主题色可调)、`stroke-width 2.6~3.5`、feather 风格;零外链、零新资产、零字体依赖。**禁无信息纯色方块/圆点占位充当图标**(历史实案:纯色矩形观感简陋被打回;改稿轮 10 处内联 SVG 全过 check/QC 为配方实证)。

## 6. 动画约束

- 禁止 `Date.now()`、`Math.random()`、无限循环;
- 只允许 transform/opacity 动画;yoyo 必须设有限 `repeat`;
- 复杂转场场景在 `.scene` div 上加 `data-layout-allow-overlap`。

## 7. 新建项目骨架(空目录从零起手)

**目录契约**(CLI 与渲染内核都按此寻址):

```
<项目>/
├── index.html               # 时间轴与场景挂载(见本文件「index.html 时间轴约定」节)
├── brand.json               # 项目内或 brands/<品牌>/ 均可,路径传 --brand
├── package.json             # scripts 见下
├── compositions/frames/     # 一帧一文件:00-cover.html、01-hook.html … NN-cta.html
├── assets/voice/            # tts 产物 *.wav(自动生成,勿手放)
├── assets/bgm/              # bgm.mp3 等背景音乐
├── assets/fonts/            # woff2 本地字体(推荐,避免跨机器回退)
├── assets/vendor/           # gsap.min.js 等本地脚本(禁 CDN,模板自带)
├── assets/img/              # 头像、产品图等
└── renders/                 # render 产物(自动生成)
```

`package.json` scripts 用本地 hyperframes(禁 npx 写法):

```json
{ "scripts": { "check": "hyperframes check", "render": "hyperframes render" } }
```

**起手顺序**:读 `references/brand-fields.md` 写 brand.json(文案先过时长预算)→ `svf build`(只跑 tts,时间轴禁预填)→ `svf probe` 拿真实时长 → 写 index.html 骨架与各帧文件(骨架从 `~/.svf/templates/` 整树拷贝,按模板 README 替换「」占位;不再从旧项目抄)→ 零参数续跑 `svf build` 出成片。

## 8. 条款战史存档(自旧版根协议迁入)

> 迁移原则:活规则只留在对应 reference,叙事性括号注(真实事故经过)归档于此。纪律铁律对照表与红旗清单的判据以 `references/red-lines.md` 为正本,不在本节复制。

- **模板探测禁 `..` 穿越**(出处:SKILL 新建项目条款):穿越式模板回退路径在首单第一步触发宿主权限弹窗,冷启动最外露摩擦。
- **点名目录外音色时 id 出口必须留**(出处:SKILL 音色条款):agent 只引导改选、不留 voice_id 出口,用户主力音色点不中。
- **单内换音色只落副本**(出处:SKILL 品牌正本与工作副本条款):单内「换成 XX」被解读为转正双写正本——披露与回退出口全履行,唯触发面宽。
- **正本只在拍板时写回**(出处:SKILL 品牌正本与工作副本条款):正本当每单工作文件用,品牌口径漂移无痕(三个历史实案)。
- **片尾收尾按 timeline 补丁收口**(出处:SKILL 首次出片第 4 步):实测收口 156.656s→154.656s、CTA 场 6.072s→4.072s——余量只加 root 不延场景窗=片尾黑屏。
- **素材在位零问**(出处:SKILL 开工确认轮条款):头像在位仍问,用户点破后自愈。
