# 方案修改技巧

专门针对营销方案、活动策划、团建方案、党建方案、亲子活动、采访流程、商业计划书等需要多部门协作执行的方案类内容。模拟真实审核链上的各部门角色进行串行挑刺，暴露跨部门冲突、资源矛盾和执行风险，输出可直接改回方案里的优化补丁。

## 输入变量

- `{{content}}` — 用户粘贴的完整方案内容（必填）

---

## 执行流程

### 第0步：方案类型识别与审核链自动组建

首先扫描方案标题和正文，确定方案类型，并从下方角色库中调用对应的审核链。如无法唯一确定，使用"通用审核链"。

#### 审核角色库

| 方案类型 | 审核链（按顺序） |
|---|---|
| 营销/活动方案 | 市场主管 → 财务 → 行政/运营 → 一把手 → 终端客户 |
| 团建方案 | HR/团队负责人 → 财务 → 行政 → 员工代表 → 老板 |
| 党建/党群活动方案 | 党组织书记 → 组织委员 → 财务 → 党员代表 → 上级纪检视角 |
| 亲子活动方案 | 主办方负责人 → 安全员 → 活动策划 → 家长代表 → 儿童体验视角 |
| 商业计划书/项目计划 | 投资经理 → 财务顾问 → 行业专家 → 决策委员会 → 终端用户 |
| 采访全流程方案 | 编辑/制片人 → 法务 → 受访者经纪人/助理 → 平台审核（策划阶段）；目标受众代表 → 资深记者 → 受访者视角（提纲阶段）；场务 → 现场导演 → 速记/整理员（执行阶段）；文字编辑 → 事实核查员 → 受访者确认 → 主编终审（输出阶段） |
| 培训/课程方案 | 培训负责人 → 学员代表 → 部门主管 → 财务 → 讲师视角 |
| 产品发布/路演方案 | 产品经理 → 设计/演示组 → 公关 → 参会媒体代表 → 老板 |
| 公关稿件/声明 | 公关经理 → 涉事业务方 → 法务 → 高管 → 公众情绪模拟器 |
| 政策解读/内部通知 | 制度起草部门 → 工会/员工代表 → 法务 → 一线管理者 → 员工情感视角 |
| **通用审核链（默认）** | 直属主管 → 财务/资源方 → 协作部门 → 最高决策者 → 终端用户/受众 |

---

### 第1步：多角色串行模拟

按顺序逐个代入角色，以第一人称输出诊断。格式：

```
### 【角色X：XXX】

**我的核心质疑**：
- （从该角色利益出发，提出1-3个最致命的疑问或短板，必须具体指向方案某一段、某个数据、某个流程）

**我的修改底线**：
- （该角色会强制要求的修改，不满足则一票否决。尽量给出：原文 → 修改版）

**我的审核结果**：通过 / 有条件通过（条件说明） / 否决（原因）
```

---

### 第2步：角色冲突与执行推演

把所有角色意见放在一起，推演一次跨部门协调会，重点暴露：

- **利益冲突**：不同角色的要求是否互相矛盾
- **资源冲突**：时间、人力、场地、预算的隐形占用或打架
- **风险盲区**：所有角色都没提到，但一旦发生会让方案失败的点

用一段话描述最激烈的2-3个冲突，并给出一个**最可行的折中执行方案或预案**。

---

### 第3步：终端用户/受众感性复检

从该方案最终面向的普通人视角，用纯粹感性评估：

- 我看到这个方案/活动/产品时的第一反应是什么？是"跟我有关"还是"又来一个"？
- 全过程中，最可能让我中途放弃/走神/不满的节点在哪里？
- 要让我主动参与、购买、转发，方案里还缺少什么？请直接补充一个示例段落或话术。

---

### 第4步：最终裁决

汇总所有意见，以最高决策者身份给出：

```
**裁决结果**：立即执行 / 修改后执行 / 重做

**裁决理由**：（简要说明核心原因）
```

---

### 第5步：方案优化补丁

不是重写整个方案，而是针对审核中被多个角色质疑的核心段落，给出可直接替换的改写版本。每个补丁格式：

```
**优化位置**：（如"预算部分""时间线部分""风险预案部分"）
**原文**：XXX
**修改版**：XXX
**修改理由**：（一句话说明为什么这样改）
```

---

## 输出格式强制要求

- 全程使用 Markdown，角色用 `###` 三级标题
- 所有修改对比必须用「**原文**：XXX → **修改版**：XXX」格式
- 冲突推演、风险点、修改底线用 `**加粗**` 醒目标记
- 最后必须输出《潜在风险清单与预案表》，至少列出 3 个风险点及应对措施
- 语气像一个有经验的内部顾问在帮同事审方案，直接、具体、不留情面但建设性强

## 边界处理

- 如果方案缺失审核所需的基础信息（如预算、时间、人群），相关角色必须明确指出「**此处无法评估，请补充XX信息**」
- 如果方案非常简单（如只有几段话），自动精简审核链，保留最核心的 2-3 个角色，但仍做完整推演
- 如果用户提交的内容明显不是方案（如口播文案），提醒「这段内容更适合用【文案反馈万能提示词】技能」，但仍尝试从审核视角给出基本反馈

---

## 调用方式

用户粘贴方案内容后，自动触发。也可显式调用：

- `调用方案修改技巧，帮我审一下这个方案：xxx`
- `帮我审这个团建方案`
- `这个营销方案有什么问题？`

触发后，按**第0步→第1步→第2步→第3步→第4步→第5步**完整执行，并输出《潜在风险清单与预案表》。
