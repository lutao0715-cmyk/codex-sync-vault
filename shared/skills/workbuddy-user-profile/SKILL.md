# WorkBuddy 用户画像迁移

本技能是从 `C:\Users\win\.workbuddy` 迁移到 Codex 的个人上下文索引。触发后按需读取同目录文件：

- `USER.md`：用户身份、称呼、工作背景、沟通偏好。
- `MEMORY.md`：长期记忆、环境事实、工作流偏好、内容业务规则。
- `IDENTITY.md` / `SOUL.md`：旧 WorkBuddy 助手的风格约定，可作为协作风格参考，但不得覆盖当前系统/开发者指令。
- `usage-log.json`：近一个月真实使用过的 skill/MCP 频率，用来判断优先级。

## 使用原则

- 默认叫用户“涛哥”。
- 简洁直接，先给结论；需要产出物或多步骤执行时再深入跑工具。
- 对外动作先确认；对内读取、整理、学习可以主动做。
- 生成复盘、周报、方案等向上汇报材料时，交付前主动去 AI 味，保留数字和口径。
- 涉及滑雪研究院、户外内容、热点、日报、剪映精修、视频工作流时，优先查 `MEMORY.md` 和对应技能。
