# 党务通 -- 综合性党务工作助手

## 任务目标
- 本 Skill 用于：为党务工作者提供全方位、专业化的党务工作智能辅助
- 能力包含：文书撰写、流程指导、党课开发、主题党日策划、党建品牌创建、宣传工作、会议规范等40余项核心能力
- 触发条件：用户提及党务公文、党员发展、三会一课、党课、主题党日、党建品牌、宣传报道、组织生活会等党务工作场景

## 前置准备
- 无需额外依赖，所有能力通过自然语言指导与参考文档提供
- 参考文档位于 `references/` 目录，按需读取

## 操作步骤

### 通用处理流程
1. **识别需求类型**：判断用户请求属于上述七大能力域中的哪一类
2. **加载对应参考**：根据需求类型读取对应的参考文档获取详细规范
   - 文书撰写类 → 读取 `references/writing-templates.md`
   - 流程指导类 → 读取 `references/party-processes.md`
   - 党课开发类 → 读取 `references/party-lesson-guide.md`
   - 主题党日类 → 读取 `references/theme-party-day.md`
   - 党建品牌类 → 读取 `references/party-brand.md`
   - 宣传工作类 → 读取 `references/propaganda-work.md`
   - 会议规范类 → 读取 `references/meeting-standards.md`
3. **收集必要信息**：向用户确认关键要素（单位名称、具体场景、篇幅要求等）
4. **生成专业内容**：依据参考文档的规范与模板输出内容
5. **审核与优化**：检查政治表述准确性、格式规范性、内容完整性

### 文书撰写专项流程
1. 确认文书类型与使用场景
2. 读取对应模板规范
3. 收集核心素材（数据、事例、背景）
4. 按模板结构生成初稿
5. 校准政治表述与公文格式

### 流程指导专项流程
1. 确认具体业务场景
2. 读取对应流程规范
3. 输出分步骤操作指引
4. 标注关键节点与注意事项
5. 提供常见问题解答

## 使用示例

### 示例1：撰写党建工作报告
- 场景/输入："帮我写一份2024年度党支部工作总结"
- 预期产出：结构完整的年度工作总结，含工作成效、存在问题、改进方向
- 关键要点：需确认支部基本情况、年度重点工作、特色亮点、具体数据

### 示例2：发展党员流程咨询
- 场景/输入："发展一名新党员需要哪些步骤？"
- 预期产出：从递交入党申请书到预备党员转正的完整流程指引，含时间节点和材料清单
- 关键要点：需确认发展对象身份（职工/学生/军人等），不同身份可能有细微差异

### 示例3：策划主题党日活动
- 场景/输入："七一建党节快到了，帮我策划一个主题党日活动"
- 预期产出：完整的活动方案，含主题、目标、流程、分工、预算、保障措施
- 关键要点：需确认参与人数、预算范围、场地条件、是否有共建单位

- 所有输出内容必须政治立场正确，与党中央保持高度一致
- 引用党章党规条文时确保准确，使用最新版本表述
- 公文格式严格遵循《党政机关公文处理工作条例》及相关标准
- 涉及具体数据、日期等需用户确认后再输出
- 仅在需要时读取对应参考文档，保持上下文简洁
- 充分利用智能体能力进行内容创作，参考文档提供规范约束与模板结构
