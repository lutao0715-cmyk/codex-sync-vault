## 党委工作报告

### 结构模板
```
标题：中共XXX委员会工作报告
称谓：各位代表、同志们：
一、过去X年工作回顾
  （一）主要成绩与成效（分3-5个方面）
  （二）基本经验与体会
  （三）存在的问题与不足
二、今后X年工作任务
  （一）总体要求与目标
  （二）重点工作部署（分5-8个方面）
  （三）保障措施
三、加强自身建设
  （一）政治建设
  （二）思想建设
  （三）组织建设
  （四）作风建设
  （五）纪律建设
结束语
```

### 写作要点
- 成绩部分用数据支撑，避免空洞表述
- 问题分析要客观实在，不回避矛盾
- 工作部署要有针对性和可操作性
- 语言庄重、简洁，体现政治高度

## 党建工作总结

### 结构模板
```
标题：XXX党支部/党委XXXX年度党建工作总结
一、基本情况（简要概述组织架构、党员队伍等）
二、主要做法与成效
  （一）强化政治引领，筑牢思想根基
  （二）夯实组织基础，提升支部战斗力
  （三）聚焦中心工作，发挥先锋作用
  （四）正风肃纪反腐，营造清正氛围
  （五）创新工作载体，激发党建活力
三、存在的主要问题
四、下一步工作思路
```

### 写作要点
- 突出"围绕中心抓党建"的导向
- 每个板块要有具体举措+实际成效
- 数据翔实：开展活动次数、参与人数、解决问题数等
- 体现特色亮点和创新做法

## 民主生活会发言提纲

### 结构模板
```
标题：XXX同志民主生活会发言提纲
一、存在的主要问题
  （一）在学懂弄通做实新时代中国特色社会主义思想方面
  （二）在坚持和加强党的全面领导方面
  （三）在履职尽责、担当作为方面
  （四）在学习贯彻党的XX大精神方面
  （五）在落实全面从严治党责任方面
  （六）其他需要说明的问题（如个人重大事项报告）
二、产生问题的原因分析
  （一）理论武装不够深入
  （二）党性修养有所放松
  （三）宗旨意识有所淡化
  （四）担当精神有所欠缺
三、整改措施与努力方向
  （一）强化理论学习，提升政治素养
  （二）锤炼党性修养，坚定理想信念
  （三）强化宗旨意识，改进工作作风
  （四）勇于担当作为，推动工作落实
```

### 写作要点
- 对照检查要具体，不能以工作问题代替思想问题
- 原因剖析要触及灵魂，不能浮于表面
- 整改措施要可操作、可检验
- 需结合上年度整改落实情况

## 请示报告

### 结构模板
```
标题：关于XXX的请示/报告
主送机关：XXX党委/组织部：
正文：
  一、请示/报告事由（为什么）
  二、具体事项/内容（是什么）
  三、请求事项/报告结论（怎么办）
结束语：妥否，请批示。/ 特此报告。
落款：XXX党支部/委员会
日期：XXXX年XX月XX日
```

### 写作要点
- 请示与报告不得混用
- 请示应当一文一事
- 语言简洁明了，事由充分

## 入党申请书指导

### 结构模板
```
标题：入党申请书
称谓：敬爱的党组织：
一、对党的认识（党的性质、纲领、宗旨的理解）
二、入党动机（为什么想入党）
三、个人履历与成长经历
四、自身优缺点分析
五、入党的决心和态度
落款：申请人：XXX
日期：XXXX年XX月XX日
```

### 写作要点
- 必须本人手写（打印稿不符合规范）
- 内容要真实，结合实际经历
- 对党的认识要准确，引用党章表述
- 入党动机要端正，避免功利化表述

## 通用写作规范

### 政治表述规范
- 党的全称：中国共产党（首次出现用全称，后续可用"党"）
- 指导思想表述须使用最新规范表述
- 涉及领导人称谓须规范
- 引用文件名称须使用全称或规范简称

### 公文格式规范
- 标题：二号方正小标宋简体
- 正文：三号仿宋_GB2312
- 一级标题：三号黑体
- 二级标题：三号楷体_GB2312
- 行距：固定值28磅
- 页边距：上3.7cm，下3.5cm，左2.8cm，右2.6cm

### 数据引用规范
- 使用权威数据来源
- 数据截止时间要明确
- 百分比与绝对数配合使用
- 同比/环比数据需标注基期
