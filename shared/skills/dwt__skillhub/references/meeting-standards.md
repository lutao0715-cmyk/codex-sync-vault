## 三会一课规范

### 支部党员大会
| 项目 | 要求 |
|------|------|
| 频次 | 每季度至少1次 |
| 参加人员 | 全体党员（可邀请入党积极分子列席） |
| 主要职权 | 听取和审查支委会工作报告；选举支部委员会；讨论接收预备党员和预备党员转正；讨论决定对党员的表彰和处分 |
| 有效条件 | 有表决权的到会人数超过应到会有表决权人数的半数 |
| 表决规则 | 赞成票超过应到会有表决权的正式党员半数方可通过 |

**基本程序**：
1. 清点人数，宣布开会
2. 奏唱国歌（重要会议）
3. 议题说明
4. 讨论审议
5. 表决决议
6. 总结部署

### 支部委员会
| 项目 | 要求 |
|------|------|
| 频次 | 每月至少1次 |
| 参加人员 | 支部委员会全体成员 |
| 主要内容 | 研究贯彻上级决议；研究支部工作计划；研究党员教育管理；研究发展党员；研究党风廉政等 |
| 有效条件 | 半数以上委员到会 |

**基本程序**：
1. 通报议题
2. 逐项讨论
3. 形成决议
4. 分工落实

### 党小组会
| 项目 | 要求 |
|------|------|
| 频次 | 每月至少1次 |
| 参加人员 | 党小组全体党员 |
| 主要内容 | 组织学习；汇报思想；开展批评与自我批评；讨论党务工作 |

**基本程序**：
1. 组织学习
2. 汇报交流
3. 讨论研究
4. 布置任务

### 党课
| 项目 | 要求 |
|------|------|
| 频次 | 每季度至少1次 |
| 主讲人 | 支部书记、委员、上级领导、先进典型等 |
| 主要内容 | 党的理论、路线方针政策；党章党规党纪；形势政策；业务知识 |
| 形式 | 集中授课、微党课、现场教学、视频教学等 |

### 记录要求
- 使用专用记录本
- 记录要素齐全（时间、地点、主持人、参加人、缺席人及原因、议题、发言要点、决议）
- 原汁原味记录发言
- 决议部分要准确完整
- 记录人签名，主持人审签

## 组织生活会

### 适用范围
- 党支部（党小组）以交流思想、总结经验教训、开展批评与自我批评为中心内容的组织生活制度
- 每年至少召开1次，一般安排在第四季度

### 会前准备
1. **组织学习**：集中学习相关文件和精神
2. **征求意见**：通过座谈、问卷等方式广泛征求意见
3. **谈心谈话**：支部书记与委员、委员之间、委员与党员、党员之间开展谈心
4. **撰写材料**：对照检查材料，查摆问题、剖析原因、明确方向

### 会议程序
1. 支部书记代表支部报告工作情况
2. 支部书记个人对照检查
3. 党员逐一进行个人对照检查
4. 开展批评与自我批评
   - 自我批评：直面问题，不回避不遮掩
   - 相互批评：出于公心，实事求是
5. 上级点评（如有上级领导参加）
6. 表态发言

### 会后工作
1. 制定整改清单
2. 明确整改措施和时限
3. 整改情况在一定范围内公示
4. 向上级党组织报告会议情况

### 注意事项
- 批评与自我批评要"红脸出汗"
- 不能以工作建议代替批评意见
- 不能以共性问题代替个性问题
- 党员领导干部要以普通党员身份参加所在支部组织生活会

## 民主生活会

### 适用范围
- 县级以上党和国家机关党员领导干部
- 每年召开1次

### 会前准备
1. **制定方案**：报上级党组织审核
2. **组织学习**：集中学习研讨
3. **征求意见**：广泛征求各方面意见
4. **谈心谈话**：做到"四必谈"
   - 主要负责同志与班子成员必谈
   - 班子成员相互之间必谈
   - 班子成员与分管部门主要负责同志必谈
   - 主要负责同志、班子成员与本人组织关系所在党支部党员代表必谈
5. **撰写对照检查材料**：
   - 查摆突出问题
   - 说明个人重大事项
   - 剖析问题根源
   - 提出整改方向
6. **上报材料**：会前向上级报送方案和个人发言提纲

### 会议程序
1. 通报上次民主生活会整改措施落实情况
2. 通报本次会议征求意见情况
3. 主要负责同志代表班子作对照检查
4. 主要负责同志个人对照检查，其他成员逐一提出批评意见
5. 班子成员逐一作个人对照检查，其他成员逐一提出批评意见
6. 督导组/上级到会同志点评
7. 主要负责同志总结表态

### 会后工作
1. 制定整改方案
2. 逐项整改落实
3. 会后15日内向上级报送会议情况报告
4. 在一定范围内通报会议情况

## 会议记录规范

### 记录要素
```
会议名称：XXX会议
会议时间：XXXX年XX月XX日 XX:XX-XX:XX
会议地点：XXX
主持人：XXX（职务）
记录人：XXX（职务）
应到人数：XX人
实到人数：XX人
缺席人员及原因：XXX（因公出差）、XXX（因病请假）
列席人员：XXX
会议议题：
  1. XXX
  2. XXX
```

### 记录内容要求
1. **发言记录**
   - 记录发言人姓名
   - 记录发言要点（不必逐字逐句，但要忠实原意）
   - 重要观点、关键数据要准确

2. **决议记录**
   - 记录表决方式（举手/无记名投票）
   - 记录表决结果（赞成X票、反对X票、弃权X票）
   - 记录最终决议内容

3. **其他事项**
   - 会议中的临时动议
   - 上级指示传达
   - 下次会议安排

### 记录格式规范
- 使用统一印制的会议记录本
- 用黑色或蓝黑色钢笔/签字笔书写
- 不得使用铅笔、圆珠笔
- 不得随意涂改，确需修改的需签名确认
- 记录完毕后记录人签名
- 主持人审阅签名

### 保管要求
- 指定专人保管
- 分类编号、归档管理
- 保存期限按档案管理规定执行
- 不得随意翻阅、复制、外借
