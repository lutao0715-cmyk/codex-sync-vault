## 新闻稿撰写

### 结构模板
```
标题：主标题（概括核心事件）
      副标题（补充说明，可选）

导语（第一段）：
  5W1H要素：何时(When)、何地(Where)、何人(Who)、
  何事(What)、何因(Why)、如何(How)
  一般不超过100字

主体：
  一、活动/事件详情
    - 具体过程
    - 重要环节
    - 关键数据
  二、领导讲话/指示要点
    - 核心观点
    - 工作要求
  三、参与人员反响
    - 党员/群众反馈
    - 表态与决心

背景资料（可选）：
  - 相关背景介绍
  - 历史数据对比

结尾：
  - 后续安排
  - 意义总结
```

### 写作规范
1. 标题：准确、简洁、有吸引力
2. 导语：开门见山，突出最重要的信息
3. 正文：倒金字塔结构，重要信息在前
4. 称谓：首次出现用全称+职务，后续可简化
5. 时间：使用具体日期，不用"近日""最近"等模糊表述
6. 数据：准确核实，注明统计口径
7. 引语：直接引语用引号，间接引语要忠实原意

### 常见类型
| 类型 | 特点 | 侧重点 |
|------|------|--------|
| 会议报道 | 程序性强 | 决议、部署、要求 |
| 活动报道 | 现场感强 | 过程、氛围、成效 |
| 经验报道 | 总结性强 | 做法、成效、启示 |
| 人物报道 | 故事性强 | 事迹、精神、品质 |
| 综合报道 | 信息量大 | 全面、系统、深度 |

## 工作简报编写

### 简报类型
1. **定期简报**：周报、月报、季报
2. **专项简报**：主题教育、专项工作
3. **会议简报**：重要会议精神传达
4. **经验简报**：典型经验推广

### 简报结构
```
报头：
  XXXX工作简报
  第X期
  XXX办公室编                XXXX年XX月XX日

正文：
  【工作动态】
  - 简明扼要报道近期工作进展

  【经验交流】
  - 推广好的做法和经验

  【问题与建议】
  - 反映存在的问题
  - 提出改进建议

  【基层动态】
  - 下属单位工作亮点

报尾：
  送：XXX
  发：XXX
```

### 编写要点
- 篇幅：每期1000-3000字
- 语言：简洁明了，不写空话套话
- 时效：及时编发，重要信息当天编发
- 审核：严格审核把关，确保信息准确

## 宣传方案策划

### 方案结构
```
标题：XXX年度/专项党建宣传工作方案

一、工作目标
  - 总体目标
  - 量化指标（发稿数量、阅读量、覆盖率等）

二、宣传重点
  - 年度重点宣传主题（按季度/月度安排）
  - 重点宣传内容

三、宣传渠道
  - 内部渠道：简报、公示栏、内部网站
  - 外部渠道：行业媒体、地方媒体、新媒体
  - 新兴渠道：短视频、直播等

四、年度宣传计划
  | 月份 | 宣传主题 | 宣传形式 | 责任部门 |
  |------|----------|----------|----------|
  | 1月 | ... | ... | ... |
  | ... | ... | ... | ... |

五、工作要求
  - 加强组织领导
  - 严格审核把关
  - 注重统筹协调
  - 强化考核激励
```

## 新媒体内容创作

### 微信公众号内容
1. **选题原则**
   - 贴近党员需求
   - 结合时政热点
   - 体现单位特色
   - 注重实用性

2. **内容类型**
   | 类型 | 适用场景 | 篇幅 |
   |------|----------|------|
   | 政策解读 | 新政策出台 | 1500-3000字 |
   | 活动报道 | 党建活动 | 800-1500字 |
   | 人物故事 | 先进典型 | 1000-2000字 |
   | 知识科普 | 党务知识 | 500-1000字 |
   | 图解/长图 | 复杂政策 | 图文结合 |

3. **标题技巧**
   - 数字法："3个要点""5步走"
   - 提问法："如何...""怎样..."
   - 对比法："从...到..."
   - 引用法：引用金句、名言

### 学习平台内容
- 课程类：微视频、音频课、图文课
- 互动类：知识答题、在线讨论
- 展示类：工作成果、典型案例

### 内容审核要点
1. 政治方向是否正确
2. 政策表述是否准确
3. 涉密信息是否脱敏
4. 图片使用是否合规
5. 文字有无错别字
