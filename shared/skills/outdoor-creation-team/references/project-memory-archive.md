# 户外视频项目记忆库

目标不是保存所有原始素材，而是保存每次成片的创作决策和结果，让后续脚本、配音、BGM、镜头匹配和剪辑更贴近用户偏好。

## 每个项目必须归档

```text
项目名/
├── 01_脚本.md
├── 02_字幕.srt 或 .vtt
├── 03_最终配音.wav 或 .mp3
├── 04_BGM信息.md
├── 05_剪辑计划.json
├── 06_成片.mp4
├── 07_复盘.md
└── 08_风格标签.json
```

## 复盘重点

- 用户保留、删除和替换了哪些镜头
- 哪些旁白与画面匹配满意，哪些不满意
- 成片节奏、开头、转场、字幕密度和镜头时长
- 配音语速、停顿、情绪和音量
- BGM 的风格、进入点、退出点和音量
- 用户明确说“以后都这样做”的偏好
- 成片发布后的数据和观众反馈（如果提供）

## 使用规则

每次新项目开始前，先读取历史项目的 `07_复盘.md` 和 `08_风格标签.json`，提取可复用规则；不要把单个项目的偶然选择直接当成永久偏好。

每次项目完成后，主动生成一份简短复盘，并把经过用户确认的偏好更新到户外专家技能的风格记忆中。原始视频素材可以继续放本地 SSD 或百度网盘，不要求全部进入知识库。

## 重要边界

项目归档会让 Codex 在未来检索和参考这些记录，但不会自动训练或修改基础模型。效果取决于项目文件是否保留、命名是否稳定、复盘是否具体。
