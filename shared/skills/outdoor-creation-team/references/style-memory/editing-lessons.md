# 剪辑经验库

记录已经被项目验证的可复用经验。每条经验包含触发场景、具体做法和来源项目。

## 经验条目

### E-001：先做素材地图，再进入剪辑执行

- 适用场景：纪录片二创、人物故事、长视频解说。
- 做法：影片和字幕 → 全片粗索引 → 脚本定稿 → 重点段落镜头级索引 → shot list → 剪辑执行。
- 原因：剪辑软件不能替代导演判断。
- 来源：户外专家团工作流。

### E-002：竖屏和横屏使用不同节奏

- 适用场景：同一素材制作多平台版本。
- 做法：竖屏通常 2–4 秒一次视觉变化；横屏通常 3–7 秒一次视觉变化。
- 来源：项目竖屏/横屏复盘规则，后续以项目复盘修正。
