```text

情绪曲线：【开头】→【发展】→【峰值】→【收束】。
要求：旁白优先、不要抢人声、不要明显歌曲主旋律、可自然循环、适合纪录片解说。
乐器与质感：【填写】。
```

## 使用规则

- 记录生成工具、账号套餐、生成日期和下载文件名。
- 不把“生成成功”直接等同于可商用；发布前核对当前授权条款。
- 记录 BGM 的实际进入点、退出点和旁白避让处理。

## 中文提示词模板（纪录片旁白版）

### 通用模板

```text
为一条关于【主题】的【视频类型】生成纯器乐背景音乐。
画面场景：【描述观众正在看到的画面】
叙事功能：用于支撑中文旁白和情绪表达。音乐必须始终处于旁白之后，不能像一首独立歌曲一样抢占注意力。
情绪曲线：【克制开场】→【逐渐发展】→【情绪峰值】→【自然收束】
配器：【填写主要乐器】
风格：【音乐类型、质感、时代感、制作风格】
速度：【慢速 / 中速 / 有推进感】，大约【BPM】拍。
混音要求：适合旁白使用，动态克制，中频柔和，为人声留出空间，不要使用明显的主旋律。
避免：人声、演唱、哼唱、合唱、歌词、说话声、流行歌曲式副歌、过强鼓点、突然结束。
时长：生成一段【多少秒】的完整纯音乐，包含干净的开头、自然的发展和清晰的结尾。
```

### 高山滑雪纪录片

```text
为一段高山滑雪探险纪录片生成纯器乐背景音乐。
画面场景：滑雪运动员在偏远雪山中遭遇暴风雪，能见度很低，在危险环境中缓慢前进，最后突破云层重新看见开阔山谷。
情绪曲线：稀疏而紧张的开场 → 不确定感逐渐增加 → 突破雪线时出现克制的情绪提升 → 安静、开阔地收束。
配器：低音弦乐、克制钢琴、深沉氛围持续音、轻微框鼓、遥远金属质感、柔和低音。
风格：电影感纪录片配乐，真实、寒冷、开阔、克制，现代电影音床，自然山地氛围。
速度：慢速到中速，大约72 BPM。
混音：适合中文旁白，编曲密度低，中频柔和，不要明显主旋律，不要突然出现巨大音量。
避免：人声、演唱、哼唱、合唱、歌词、说话声、预告片式轰鸣、EDM爆发、英雄主义流行旋律、过度鼓点。
时长：60秒，包含克制开头、逐渐发展的中段和自然结尾。
```

### 滑雪突破、冲坡、竞速

```text
为一段极限滑雪运动纪录片生成纯器乐电影感配乐。
画面场景：滑雪运动员从陡峭粉雪坡顶出发，高速穿越狭窄地形，完成一次危险而精彩的下降。
情绪曲线：专注和等待 → 身体运动感增强 → 下降过程中出现短暂而克制的情绪峰值 → 完成后的压力释放。
配器：脉冲感低音弦乐、低沉太鼓、紧凑但克制的电影感打击乐、颗粒感合成器脉冲、稀疏铜管渐强，不要明显主旋律。
风格：现代户外纪录片，具有动能但保持克制，电影感紧张氛围，寒冷空气感，身体运动感，高品质体育纪录片配乐。
速度：有推进感但不要过快，大约100 BPM。
混音：适合中文旁白，中频清晰，不要让鼓点持续压住人声，用短促节奏强调替代持续重型鼓点。
避免：人声、演唱、哼唱、合唱、歌词、节日EDM、摇滚副歌、夸张预告片重击、从头到尾保持同样强度。
时长：45秒，开头克制，中段推进，结尾干净，方便与旁白衔接。
```

### 户外人物故事

```text
为一段户外人物故事纪录片生成纯器乐背景音乐。
画面场景：一名户外运动员离开家乡，经历多次失败，在漫长训练中独自坚持，面对季节变化仍然没有放弃。
情绪曲线：亲密、克制的开场 → 安静的失落 → 希望逐渐累积 → 温暖但不完全封闭的结尾。
配器：柔和毡制钢琴、低沉大提琴、轻微木吉他、柔和弦乐、非常克制的打击乐。
风格：以人物为中心的纪录片配乐，亲密、真实，温暖但不煽情，克制的电影感叙事。
速度：慢速，大约65 BPM。
混音：给中文旁白留下充足空间，和声简单，编曲密度低，不要抢注意力的旋律。
避免：人声、演唱、哼唱、合唱、歌词、过度煽情钢琴、商业励志音乐、过于明亮的大调结尾、戏剧化预告片推进。
时长：90秒，柔和开场、缓慢发展、克制结尾。
```

### 雪山、湖泊和自然风景

```text
为一段自然风光纪录片生成纯器乐氛围音乐。
画面场景：雪山、冰封湖泊、风吹过空旷山谷的远景，画面中几乎没有人物，整体节奏缓慢而开阔。
情绪曲线：安静 → 细微惊叹 → 空间感逐渐扩大 → 平静淡出。
配器：柔和毡制钢琴、空气感铺底、轻微玻璃摩擦质感、自然环境氛围、非常轻的弦乐。
风格：极简电影感氛围音乐，自然、开阔、沉思，高品质户外纪录片，让画面有呼吸感。
速度：非常慢，大约55 BPM，不要明显节拍。
混音：非常适合中文旁白，音乐密度低，高频柔和，不要强节奏，不要明显主旋律。
避免：人声、演唱、合唱、歌词、流行歌曲结构、戏剧化鼓点、强烈低音、突然转场。
时长：60秒，听起来可以自然循环的纯音乐。
```
