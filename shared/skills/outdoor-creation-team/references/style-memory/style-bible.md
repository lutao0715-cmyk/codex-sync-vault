# 户外视频风格总库

这是涛哥长期稳定的创作偏好。每完成一批视频后，只更新已经被反复验证的规则，不把单条视频的偶然选择直接写成长期规则。

## 账号区分

- 滑雪研究院：专业、资讯、教学、滑雪人物和行业内容。
- 泛户外账号：陆地、水上、雪上、跑步和生活方式，强调真实体验与场景差异。

## 默认创作原则

- 先理解影片和素材，再写脚本；脚本定稿后再做镜头级索引。
- Codex 负责导演判断、脚本、素材地图和 shot list；DaVinci 负责时间线执行。
- 画面要服务口播，不能为了填画面堆无关 B-roll。
- 旁白、原声、环境声和 BGM 先分配职责，再做混音。
