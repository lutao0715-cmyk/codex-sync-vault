# 纪录片剪辑四阶段提示词

适用于“Codex + DaVinci Resolve”的纪录片解说、人物故事和户外素材剪辑。四个阶段必须按顺序推进：先分析素材，再根据定稿脚本找画面，再生成 shot list，最后让 DaVinci 执行粗剪。

## 阶段一：分析素材

```text
你现在是纪录片剪辑导演，不要直接剪辑。

请先按 `media-tool-routing.md` 选择本地 `video-understanding` 或 TwelveLabs Jockey，读取当前项目中的影片、字幕和素材信息，建立“可剪辑素材地图”。

输出：
1. 全片故事结构；
2. 主要人物和事件；
3. 每个重要段落的开始和结束时间码；
4. 值得二创的 A/A+ 段落；
5. 每个段落的画面内容、情绪、冲突和镜头价值；
6. 适合二创使用的镜头；
7. 不适合使用的镜头；
8. 需要重点回看的段落。

若使用 Jockey，同时保留 knowledge store、item id、候选片段时间码和命中依据。语义命中不得直接当作事实或最终镜头结论。

本轮只分析，不修改 DaVinci 时间线。
```

## 阶段二：根据脚本找画面

```text
下面是已经确认的中文解说稿。

请不要改写解说稿，只根据解说稿反推画面。

为每一段输出：
- 解说句；
- 推荐素材；
- 原片时间码；
- 镜头类型；
- 镜头功能；
- 建议使用时长；
- 是否保留原声；
- 是否适合竖屏；
- 画面和口播不匹配时的风险。

只选择与这句口播有明确关系的镜头。
如果没有可靠匹配，不要猜，标记为“缺少可靠画面”。
```

## 阶段三：生成 shot list

```text
根据已确认的解说稿和镜头索引，生成 DaVinci shot list。

字段必须包括：
镜号、时间码、源素材、入点、出点、镜头内容、镜头功能、口播对应句、视频轨、音频轨、转场、字幕、花字、音效、BGM 段落、竖屏裁切风险、是否保留原声。

先输出执行单，不要修改时间线。

完成后检查：
1. 有没有重复素材；
2. 有没有时间码重叠；
3. 有没有一句口播没有画面；
4. 有没有画面和口播逻辑冲突；
5. 有没有不适合竖屏的镜头。
```

## 阶段四：执行粗剪

```text
请基于已经确认的 shot list，通过 DaVinci Resolve MCP 执行粗剪。

安全要求：
1. 先复制当前时间线；
2. 只修改副本；
3. 不覆盖原素材；
4. 不自动替换素材；
5. 不改变项目帧率和分辨率；
6. 不在未经说明的情况下删除原声；
7. 所有写入操作前先汇报计划；
8. 执行后报告实际修改的时间线、片段和时间码。

完成后检查：
- 黑帧；
- 空白帧；
- 音画不同步；
- 字幕越界；
- 竖屏主体出框；
- BGM 压住人声；
- 转场过度；
- 渲染设置是否符合目标平台。

执行后读取实际时间线状态核对，不只依据调用成功信息判断完成。
```

## 使用纪律

- 阶段一没有完成素材地图，不进入阶段二。
- 解说稿没有定稿，不做大规模镜头级索引。
- 阶段三的 shot list 没有确认，不让 DaVinci 修改时间线。
- 阶段四只操作副本时间线，母版和原始素材保持不动。
- 纪录片长素材仍遵循“全片粗索引 → 重点段落精细索引”的规则。
