# 直播复盘（直播/内容活动复盘）

> 本 skill 原名 `live-activity-retrospective`，v1.2 起更名为「直播复盘」。

**核心原则：结论先行、每个判断都挂着可复算的数字、口径写在正文里、数据全图表化、定性评价配真实截图。**

## 必算的指标体系（复盘骨架）

- **漏斗**：报名 → 审核通过 → 实际开播 → 完成基础任务；每层人数 + 转化率 + 拒绝原因分类。
- **目标达成对照表**：逐条对齐方案目标（活跃主播数、人均/累计有效场次、**播放时长**、ACU>N 场次、拉新）。
  - **播放时长通常是方案里的第一消费目标**，要单独重点写（见 §北极星指标写法）。
  - 口径不一致时明确写「口径不可直接对比」，不要硬凑达成率；能算出对照基线的（如方案测算逻辑里的「600 场 × 场均 7h ≈ 4,200h」）要给倍数。
- **总量**：场次、开播时长、播放时长、有效场次占比、曝光/点击/播放/互动/关注（标明「场次求和、未去重」）。
- **走势**：逐日场次 + 场均 ACU；首周 vs 末周（场次/播时/场均 ACU/开播人数）→ 论证「冷启动期约两周」。
- **主播个体变化**：按主播聚合 场次/有效场次/开播h/播放h/ACU/互动/关注 + **前段 vs 后段对比**（按活动中点切），分三类：高成长 / 稳定 / 掉队；并算 **TOP5/TOP10 播放时长集中度**（头部依赖风险）。
- **效率与异常**：播放h÷开播h（内容效率）、互动次数 vs 互动用户数（识别刷互动/少数高频用户）、场次多但有效少的（多开/凑时长）。
- **内容分层**：结合运营评价（评价在明细表里，**直接引用原文**）把主播分 4 层（优/潜力/凑数/淘汰），每层配截图。

## 北极星指标写法（播放时长专项，v1.1 新增）

播放时长是这类活动最容易被领导追问的指标，固定按这四层写：

1. **对照基线**：方案测算逻辑里的推算值（如 Q2 非赛场均播时 7h、600 场 → 约 4,200h）。
2. **实际与倍数**：实际总播放小时数 ÷ 基线 = 几倍；场均播放时长 ÷ 基准场均 = 几倍。
3. **占大盘比例**：本次实际 ÷ 方案总目标（如 13.9 万小时）→ 得出「本模块只能贡献约两成，其余需其他模块承接」的资源结论。
4. **结构集中度**：TOP5 / TOP10 主播贡献占比 → 头部依赖风险 + 二期锁定头部的动作。

写成一个 `callout` 高亮块放在「目标达成」标题正下方，不要埋在表格里。

## 红线

- 不编造数据：源表没有的字段（如「拉新用户数」）就写「表未设该字段，以 XX 近似参考，待核」，不要估算。
- 不把当次活动的口径套到别次活动；每次先看表头再算。
- 表格里的主播昵称、sheet 名、指标名逐字保留。
- **用户给的对照数据 vs 自己的统计不一致时，必须先自查再解释**：先查分母/口径/去重，最后才谈「口径不同」。
- 结论段避免「相关性当因果」；运营评价一律标注为**主观评价**，与数据并列而不是替代。
