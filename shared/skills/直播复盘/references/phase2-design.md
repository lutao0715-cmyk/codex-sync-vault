# 二期方案设计（复盘做完之后怎么做下一期）

> 使用时机：用户说「我要做第二期了」「老板不增预算怎么办」「算法团队觉得给流量做活动效率低」「帮我设计下一期活动」。
> 核心：**不要重新拍脑袋设计，用一期复盘数据算出「效率分档」，把方案变成分配规则的调整。**

## 一、先算三张表（没有这三张表，方案就是空话）

### 表1：主播级效率分档（最重要）

按「次均曝光播放时长 = 播放时长(h) × 3600 ÷ 曝光次数」把**全部**参与主播排序。

> ⚠️ 必须用「活动归因的全部场次」（含未达标场），只算有效场次会系统性高估效率。

分档（阈值可按活动调整，下面是实测好用的）：

| 档位 | 阈值 | 含义 |
|-|-|-|
| 高效组 | 次均 ≥14 秒 | 已达/超过自然流量水平 |
| 中效组 | 9–14 秒 | 接近，有提升空间 |
| 低效组 | <9 秒 | 纯消耗，是效率被拉低的元凶 |

每组各算：人数、曝光次数、曝光占比、播放时长、时长占比、组内次均。**曝光占比 vs 时长占比的错配就是整个二期方案的立论基础。**

### 表2：自然流量基线

从「活动前一个月的同批主播」算加权次均曝光播放时长，作为 baseline（本次实测 16.64 秒）。
护栏线 = 基线 × 70%。低于护栏线的主播不给活动流量加成。

### 表3：零成本增量空间

```
低效组次均 × 高效组次均 → 差值为 gap
每转投 100 万次曝光 = 1,000,000 × gap ÷ 3600 小时（本次实测 +3,439h，约总时长的 12.8%）
```

这个数字是回应「不增预算」的核心证据：**同样的流量换个投法，就能多出两位数百分比的时长产出。**

## 二、三方约束的翻译公式

| 对方说 | 真实约束 | 翻译成可执行动作 |
|-|-|-|
| 老板：「总激励不增加」 | 只能改**分配方式**，不能改**总额** | 预算拆三池（保底/效率/留任），单价下调 + 效率奖金，头部收入不降反升 |
| 算法：「给主播活动效率低」 | 他们按「每次曝光带来的时长」考核 | 用表1 证明是**分配平摊**不是活动本身；改成流量分档授权 + 额度可回收 |
| 自己：「想推进」 | 缺一个让对方不亏的结构 | 用「交换物清单」把索取变成交易 |

> **关键认知**：算法团队的反对通常有数据支撑（本次：活动流量 8.26 秒/次 vs 自然 16.64 秒），硬顶没用。
> 破局点在于证明**这个平均值是被低效主播拉低的**——剔除后能反超自然流量。

## 三、方案十项改动清单（模板）

1. **流量从普惠配额 → 分档授权**：A 档不限量滚动续投 / B 档基础额度+双周加量 / C 档零加成。
2. **效率护栏**：低于自然基线 70% 连续两周自动降档；低于 8 秒额度回收。
3. **回收额度回归算法侧**（换取支持的关键让步，必须明确写）。
4. **交换物清单**（让对方觉得赚）：垂类内容池 / 拉新用户留存样本 / 免费 A/B 实验位 / 效率实验报告。
5. **预算三池重构**（总额不变）：保底 40%（单价降至一期 0.7）+ 效率 40%（按时长分档结算）+ 留任 20%（签约金分三期）。
6. **非现金激励置换**：把其他场景的变现机会、资源位、官方号联推计入激励，减少现金支出。
7. **名额提纯**：一期人数的 60–65%，补位标准加「非赛内容能力一票否决」+ 曝光效率预估；目标 A/B+ 占比 ≥50%。
8. **门槛加厚**：场次 + 效率达标场次双门槛；单场最低时长从 2h 提到 2.5h（治「达标即停」）。
9. **报名制 → 合约制**：报名表单加 aid 唯一校验；双向承诺书；双开条款二选一（签排他 or 按本侧产出折算）；违约条款前置。
10. **过程管理**：周维度看板（场次 / 次均曝光时长 / 内容合格率）+ 三条预警线 + 48h 1v1 + 连续两周 D 档提前退出并把额度转给 B 档补位。

## 四、赛道结构：钱花在能打的地方

用赛道级「点击率 + 次均曝光播放时长 + 场均 ACU + 互动率」四象限决定加量/提质/砍配额：

- 双料第一 → 加量（本次：钓鱼）
- 规模与 ACU 双高 → 保持为主力（本次：舞蹈）
- 规模大但同质化 → 提质不减量，1v1 内容改造（本次：健身）
- 三垫底 → 配额砍半（本次：娱乐）
- 点击率垫底但留存/互动好 → 只留头部，重做封面/标题模板（本次：赛事聊天）

## 五、考核口径统一为算法语言

- 核心 KPI：**次均曝光播放时长**（首要）+ 有效曝光播放转化率 + 达标场次
- 播放时长**总量降为过程指标**（当唯一 KPI 会直接导致「挂时长凑场次」）
- 归因：报名名单为唯一合法口径，活动标识不外发，报表默认按名单过滤

## 六、对上汇报的两个口径（各一句话）

- **对老板**：「盘子不增，产出结构从『场次』变成『时长效率 + 可复用主播资产』。单位曝光产出能从 X 秒提到 Y 秒区间，头部留得住。」
- **对算法**：「不是给主播要流量，是给你一个可回收的实验位。只投 N 个效率已达标的主播（现成 X 秒 > 自然 Y 秒），不达标的额度次日回到你的池子；另外附送垂类内容池 + 拉新用户留存样本 + 实验位。」

## 七、留 5 个决策点给对方拍板（不要自己全定）

名额上限 / 护栏线阈值 / 回收额度归属 / 三池比例 / 双开条款。
把选择权交出去，方案才推得动。
