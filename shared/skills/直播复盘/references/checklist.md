# 口径统一 / 交付自查 / 坑表（checklist）

## 一、口径统一规则（最重要）

**同一次复盘里，比率的分子分母必须全程同口径，并在正文标明。** 常见两套口径：

| 指标 | 人数口径 | 次数口径（平台/同事常用） |
|-|-|-|
| 点击率 | 点击用户 ÷ 曝光用户 | 点击次数 ÷ 曝光次数 |
| 互动率 | 互动用户 ÷ 播放用户 | 互动次数 ÷ 播放次数 |
| 涨粉率 | 关注数 ÷ 播放用户 | 关注数 ÷ 播放用户 |

**处置流程（当用户说「你统计的和别人不一样」）**：

1. 先把逐个总量指标复算一遍，与对方数字**逐项列表对比**（场次/时长/曝光/点击/播放/互动/关注）。
2. 总量都能对上 → 差异大概率是**比率口径**或**分母错误**，不是数据错。
3. 检查自己的分母是否含空行、是否含未开播主播、是否漏了某些场次。
4. 最终统一到**对方/平台的口径**（便于对账），人数口径作为补充说明保留。
5. 文档里写清楚「本表口径：次数口径；人数口径为 X」，别让领导自己猜。

## 二、交付前 12 项自查

- [ ] 1. 每个比率都输出了 `分子 / 分母` 原始值并人工看过
- [ ] 2. 空行已过滤（数据行 = 有主键的行数，不是表格总行数）
- [ ] 3. 日期解析正确（8 位数字日期已切分年月日）
- [ ] 4. 前后半程切点与活动周期一致，且两段都有数据
- [ ] 5. 目标达成表逐条对齐方案原文，口径不可比的**明确写出口径差异**
- [ ] 6. 播放时长按「对照基线 → 倍数 → 占大盘比例 → 集中度」四层写完
- [ ] 7. 源表没有的字段不估算，写明「表未设该字段，以 XX 近似，待核」
- [ ] 8. 运营评价标注为「主观评价」，与数据并列，不混为一谈
- [ ] 9. 图表数字与正文数字一致（同一指标在表和图上不同是最常见的硬伤）
- [ ] 10. 图片全部落地（`fetch --doc-format markdown` 数图片数）
- [ ] 11. 旧口径残留为 0（搜索被修正过的旧数字/旧百分比）
- [ ] 12. 文档链接可访问 + 用 `present_files` 交付

## 四、与「同事版本」的关系（用户明确要求）

用户会拿同事的复盘当参考，且要求**做得更专业**：

- 借：章节骨架、必要的背景交代。
- 超：① 每个判断挂可复算数字；② 口径写在正文而非附录；③ 图表化；④ 目标达成写倍数与占比；⑤ 结论给出可执行动作与验证门（量化阈值）。
- 不要：照抄他们的口径错误（如报名人数少一行、分母含空行），发现问题在提交时口头说明差异，而不是静默采用。
