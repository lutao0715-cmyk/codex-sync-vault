# 算法侧「作者场景明细」审计分析

算法团队常会提供一份《非赛二台作者分析》类明细，用于讨论「给主播活动流量效率高不高」。
它的价值不在总量，而在**入口/场景（SPM）维度**和**深浅指标**——这是运营侧数据（跨天表）没有的。
本文档记录该文件的解析口径、分析框架与结论模板。

## 1. 典型文件结构（10 个 sheet）

| Sheet | 粒度 | 关键字段 / 用途 |
|---|---|---|
| 作者名单 | 名单 | 算法侧认为值得看的作者清单 |
| 作者直播明细 | 作者 × 场次 | 赛道、账号评级、开播时长、赛事归属 |
| 作者算法场景曝光 | 作者 × 汇总 | 曝光/点击/播放/有效播放次数，PV CTR、UV CTR、次均播放时长、人均播放时长 |
| **作者分场景曝光** | **作者 × SPM** | **主表**：同一作者在不同入口的表现，可做场景错配分析 |
| 作者分时间曝光 | 作者 × 天 | 效率随时间衰减 |
| 作者互动 | 作者 × 汇总 | 有效直播口径、≥60s / ≥300s 完播、进房（entry_home）、分享/聊天/打赏/点赞 |
| 作者分时间互动 | 作者 × 天 | 同上按天 |
| 非赛二台大盘 | 天 | 非赛事内容的整体基准线 |
| 赛事二台大盘 | 天 | 赛事内容的整体基准线（回答「流量给谁更值」） |
| 二台场景大盘 | SPM | 全站场景基准，可与作者分场景对比（作者在该场景是跑赢还是跑输） |

## 2. 口径红线（务必先对齐，否则结论全错）

1. **曝光口径不同**：算法文件只统计**算法推荐场景**曝光（千万级），跨天表是全入口（亿级）。
   → 两份表的 CTR / 人均时长**不可跨表比较**，只能各自内部比。
2. **CTR 列有两种存法**：作者表是**小数**（0.1438），场景大盘表是**百分数**（6.66）。
   → 一律自己用 `点击次数 / 曝光次数` 重算，别直接取列。
3. **时长口径不同**：算法「点击视频总播放时长」高于跨天表「直播播放总时长」（口径含视频播放）。
   同样不可跨表相加。
4. **互动/播放 > 100%** 说明互动次数口径含多次计数，不能当作「互动率」解读。
5. **名单 gap 是常态**：本次 29 位中 28 位与运营主口径重合，仅 1 位新面孔；
   运营侧另有 6 位（多为小样本 / 末层主播）未被覆盖。按名字对齐即可，不必强行凑数。

## 3. 场景分型（把 40+ 个 SPM 归成 8 类）

```python
def kind(spm):
    s = str(spm)
    if '挂件' in s: return '挂件页'
    if '我的频道' in s: return '精选页·我的频道'
    if '双排feed' in s: return '精选页·双排feed'
    if '详情页' in s or '上下滑' in s: return '详情页'
    if '搜索' in s: return '搜索页'
    if '沉浸式视频流' in s or '短视频' in s or '底导' in s: return '短视频流'
    if '榜单' in s: return '榜单'
    if '精选页' in s: return '精选页·其他位'
    return '专区/其他'
```

**判定顺序很重要**：`挂件/我的频道/双排feed/详情页` 必须先判，否则会被 `精选页` 兜底吃掉。

## 4. 核心指标

- **效率指数 = 时长占比 ÷ 曝光占比**（>1 表示该场景产出效率高于平均）
  - 一次算完全场场景，就能一眼看出「曝光投错地方了吗」
- **低效场景占用率** = 该主播在低效场景（双排feed / 榜单 / 短视频流 / 精选页其他位）的曝光 ÷ 其总曝光
  - 这是**判断「效率差是主播问题还是分配问题」的关键变量**
  - 用它与「次均播放时长」「CTR」做相关性；本次 r = −0.72 / −0.61
- **同场景内横向对比**：固定一个场景看多名主播的 CTR 区间，用来**分离「场景红利」与「封面/内容能力」**

## 5. 分析结论模板（本次实测）

1. **大盘定位**：把主播组放进「非赛二台大盘 / 赛事二台大盘」两个参照系，
   往往得到「CTR 居中、停留强于非赛、明显弱于赛事」的结论 —— 直接回应算法侧的质疑。
2. **错配结论**：本次 38.8% 曝光投在「精选页·双排feed」（效率指数 0.04×），
   仅产出 1.5% 时长；而「详情页」（4.5×）、「我的频道」（1.7×）、「挂件页」（1.3×）吃掉大部分产出。
3. **归因结论**：低效场景占用 <50% 的 6 人平均次均 213s，≥50% 的 23 人平均 77s（2.8 倍差）。
   → 「效率低」主要是**分配问题**，不是内容问题。
4. **个人能力仍有作用**：同一低效场景内 CTR 区间可达 6 倍；高效场景内头部主播 CT 断层第一。
   → 双维度结论：**场景决定上限，封面/内容决定相对位置**。

## 6. 衍生用法

- 二期方案：把「场景配额」写进资源谈判（换场景 ≠ 要更多流量，算法侧阻力更小）
- 表格里可直接复用的一句话：「不是给主播要更多流量，是把 38.8% 的错配曝光换到产出效率 4.5 倍的详情页」
