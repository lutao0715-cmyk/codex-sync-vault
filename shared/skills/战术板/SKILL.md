# 战术板

> 原名 `ai-tactics-board-schedule`，2026-09-22 起定名「战术板」，作为独立技能长期使用。

**一句话**：丢一份赛事总表进来 → 出《（AI战术板）正式排期》xlsx。版式、取数、频道分配全部自动化，不需要每次重新交代规则。

## 输入

1. **总表**（必需，xlsx）——含每场比赛多路信号的运营总表。典型文件名：《CFA中国之队&英女超9.24-10.6.xlsx》《副本CFA…》等。
   21 列 = 排期id | 排期名称 | 节目日期 | 节目开始时间 | 比赛时间 | 节目结束时间 | 赛事 | 轮次 | 演播室 | 场馆 | 解说/嘉宾 | 收费策略 | 信源通道 | 所属频道 | 主路信源地址 | 备路信源地址 | 频道媒资ID | 频道内容ID | 节目单内容ID | **PID** | 节目单节目ID
   同一场比赛（同一 **PID**）有多行信号路：主路（名称**不带括号备注**）、（赛场原声）、（后方解说）、（清流50P不播出）等。
2. **模板**（默认 `~/Desktop/（AI战术板）正式排期(2).xlsx`）——提供 21 列版式、红底表头、列宽、单元格格式。若被移动/改名，问涛哥要最新路径并用 `--tpl` 指定。

## 执行

```bash
cd ~/.workbuddy/skills/战术板
C:/Users/win/.workbuddy/binaries/python/envs/default/bin/python build_schedule.py "/path/to/总表.xlsx"
```

- 不传总表路径时，脚本会自动在桌面找最新的非输出 xlsx；模板同理有默认值。
- 可选参数：`--tpl 模板.xlsx`、`--out 输出.xlsx`、`--channels 269,270`（未来频道扩容时用）。
- 默认输出：`~/Desktop/（AI战术板）正式排期_<总表名去「副本/最新/总表」前缀>.xlsx`。
- 跑完**必须回读校验**（见下），再用 `present_files` 交付。

## 生成规则（核心，不要自创版式）

| 目标列 | 取值规则 |
|-|-|
| 排期名称 | 总表「（赛场原声）」行的名称，把「（赛场原声）」换成「**（AI战术板）**」 |
| 节目开始日期/时间、比赛日期/时间、节目结束日期/时间 | 全部取该「赛场原声」行 |
| 预计推流日期/时间 | = 节目开始日期/时间 |
| 预计断流日期/时间 | = 节目结束日期/时间 |
| 赛事 / 轮次/项目 / 场馆 / 解说嘉宾 | 取原声行 |
| **演播室** | **固定文案「AI战术板不播出」**（2026-09-23 起不再取原声行的值） |
| **收费策略** | 取同 PID 组**主路**：组内名称**不含括号**的行；没有则取含「主赛场/主路」的行（如「中国vs新西兰（咪咕主赛场）」）；再无取组内第一行。⚠️ 结果常与原声路相反（主路免费、原声收费） |
| **备注** | 频道号，见下节 |
| 通道标签 / 能力类型 | 留空 |
| 赛季 | 按 `SEASON_MAP`，目前仅英女超 = 2027；其余留空 |

- **版式**：以模板文件为底，只替换数据行；21 列红底表头、列宽、格式（日期 `m"月"d"日"`、时间 `h:mm:ss`）原样保留，sheet 名 `体育类`。
- **节目结束日期**：总表里已是完整 datetime，直接用其日期部分（跨天自动正确，**不要**再自行 +1）。
- 全部静态值，**不写公式**（本机无 LibreOffice，公式无法重算）。

## 备注列 = 频道抢号（最易踩坑的一环）

**只有 269、270 两个频道可用。**

1. **冲突定义**：两场节目的 `[节目开始时间, 节目结束时间]` 有交集（`startA < endB and startB < endA`）。**首尾相接不算冲突**。
2. **抢号顺序 = 比赛热度从高到低**（同热度按开始时间、总表原顺序）：
   - **中国比赛永远最高**（`CHINA_HEAT = 100`，必抢到号）；
   - 其余比赛热度 = **两队中较高者**，在 `MEN_HEAT` / `WOMEN_HEAT` 里按**子串**匹配队名，认不出按 `DEFAULT_HEAT=40`；
   - **男女足热度表分开、不通用**（女足单列 `WOMEN_HEAT`）。
3. **抢不到就留空**：两个号都被重叠场次占着时，备注**什么都不填**，绝不扩到 271+、也不共用频道。
4. 脚本内置冲突自检，会打印「重叠却同频道的情况」，**必须为 0**。

**热度表位置**：`build_schedule.py` 顶部可配置区。五大联赛开赛后按需调数值即可，算法不用动。
- 男足已覆盖：英超（曼城93 阿森纳94 利物浦91 曼联92 切尔西90 热刺88）、西甲（皇马96 巴萨95）、意甲（尤文88 国米88 AC米兰87）、德甲（拜仁93 多特85）、法甲（巴黎92）等。
- 女足：切尔西女足90 阿森纳女足90 曼联女足89 曼城女足88 利物浦女足86 托特纳姆热刺女足84 …

> 实测（2026-09-22 首批 21 场）：269 占 11 场、270 占 3 场、**7 场留空**。全场 0 冲突。

## 交付前回读校验

用 openpyxl 回读输出文件，逐项确认：

1. 行数 = 总表「（赛场原声）」行数（首批为 21）；
2. 表头 21 列与模板逐字一致、A1 红底（`FF0000`）、B2/C2 格式为 `m月d日` / `h:mm:ss`；
3. 收费策略列是否合理（多数为「免费」）；
4. 跨天场次「节目结束日期」是否比开始日期大 1 天；
5. 备注列只用 269/270 或空；
6. 脚本自检「重叠却同频道」= 0。

## 踩坑记录

- **PID 不是 `rest[2]`**：按位置解包时，第 15~21 列依次是 主路信源地址/备路信源地址/频道媒资ID/频道内容ID/节目单内容ID/**PID**/节目单节目ID → PID 是 `rest[5]`。用错列做分组键会导致每组只有一行，收费策略全取错。**现行脚本已改为按表头名定位列，不再依赖位置**。
- **总表 sheet 名不固定**：可能是 `Sheet0`（副本导出）或 `Sheet1`。现行脚本自动找含「PID/排期名称」表头的 sheet。
- **Edit 工具偶发「报成功但内容没变」**：改完必须 grep / Read 回读确认再跑。
- **模板表头第 2 列是「节目开始日期」**（不是「节目日期」）、第 4 列是「比赛日期」，别照总表列名写。
- 本机无 LibreOffice / Python `formulas`，所以全表静态值、不要写公式。
