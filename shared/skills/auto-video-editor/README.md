# 自动剪辑台 · auto-video-editor

本机跑的视频自动剪辑 + 音频处理引擎，带一个窗口化的剪辑面板。
底层是 ffmpeg，节拍分析用 numpy，**全程离线，素材不出本机**。

## 30 秒上手

```sh
./run.sh doctor --fix     # 第一次：自动装 ffmpeg + numpy（只装进本目录）
./run.sh panel            # 开面板，浏览器里操作
```

命令行直接出片：

```sh
./run.sh auto in.mp4 -o out.mp4 --mode silence     # 去静音
./run.sh auto in.mp4 -o out.mp4 --mode scene       # 按镜头切
./run.sh auto in.mp4 -o out.mp4 --mode beat --music bgm.mp3   # 卡点
```

## 它能做什么

| 能力 | 说明 |
|---|---|
| **去静音** | 口播 / 教程 / 访谈剪废话。可「直接删掉」或「静音段加速播放」 |
| **分镜切分** | 按镜头切换点自动切段，适合素材整理、批量拆条 |
| **卡点** | 从音乐里提节拍，按拍切；单素材跳剪，多素材做素材墙 |
| **切片与变速** | 任意区间裁切、拼接、0.1×~100× 变速（音高不变） |
| **音频处理** | 降噪 / 低切高切 / 噪声门 / 三段 EQ / 压缩 / 立体声 / 增益 |
| **响度与收尾** | 两遍 loudnorm 精确归一化、限幅、淡入淡出、原声与 BGM 混音 |
| **输出适配** | CRF 画质控制、竖屏/方形裁切、批量转码 |

### 音频处理怎么用

```sh
./run.sh auto in.mp4 -o out.mp4 --audio-preset voice     # 口播/配音
./run.sh audio in.mp4 --measure                         # 先量底噪、信噪比、工频哼声
./run.sh audio in.mp4 -o voice.m4a --denoise standard    # 只处理音频，不碰画面
```

面板里对应「音频处理」一栏：预设下拉 + 「自动」（按实测底噪填参数）+
「试听处理后的音轨」（走和成片完全一样的处理链）。

| 预设 | 适用 |
|---|---|
| `voice` | 室内口播、解说 |
| `interview` | 访谈、多人、房间反射多 |
| `outdoor` | 户外、Vlog，风噪与持续环境噪 |
| `rescue` | 底噪大、有削波的废片 |
| `hum` | 50Hz 交流哼声、空调嗡嗡声（只做低切，降噪器对此无效） |
| `music` | 音乐内容，只走响度与限幅 |

**四条实测结论**（细节见 SKILL.md，都是扫描验证过的，别推翻）：

1. **「更强的降噪」不存在。** 加深 afftdn 只会连人声一起削：`nr=12 nf=-44` 的
   SNR 增益 +5.0dB，`nr=20` 掉到 +2.8dB，`nr=30` 归零，`nr=40` 变负。
   所以「强降噪」实际是「标准降噪 + 一道噪声门」，而不是更狠的降噪。
2. **级联两级 afftdn 有害**，第二级会误判并注入伪影（实测噪声不降反升 5dB）。
3. **工频哼声只能靠低切**，任何降噪器对它都无效。
4. **响度必须走两遍 loudnorm**，单遍动态模式在短片上来不及收敛，实测偏 1.5dB。

自带带标准答案的测试素材（`tests/make_fixtures.py` 合成），三套检测全部实测通过：

| 检测项 | 结果 |
|---|---|
| 静音段 | 6/6 命中，边界误差 ≤ 0.072s |
| 镜头切点 | 3/3 命中，误差 0.000s |
| 节拍点 | 59/59 命中，偏差 ≤ 0.048s，BPM 117.5（实际 120） |
| 全量分析耗时 | 24s 音频约 0.13s，30s 音乐约 0.24s |
| 渲染 | 16s 视频 320×180 约 1.1s |

## 依赖

不需要 Homebrew、不需要管理员权限。`doctor.py --fix` 会把静态 ffmpeg 和 numpy
装进本目录的 `bin/` 和 `.venv/`。

想用系统自己的 ffmpeg：设 `AVX_FFMPEG` / `AVX_FFPROBE` 指向即可。

## 它做不到什么

这套东西做的是**粗剪**，不是精修。

- ❌ 画面特效：转场、调色、滤镜、关键帧动画、字幕样式
- ❌ 语义理解：它不知道「这段讲得不好」，只认信号强度
- ❌ 语音转写 / 自动字幕（需另接 whisper）
- ❌ 人声/伴奏真分离。面板里的「人声靠前 / 去人声」是 mid-side 矩阵近似，
  不是声源分离——对中置人声的普通立体声混音有效，对已做宽的人声基本无效。
  且「人声靠前」只在立体声下成立，单声道折叠后无从体现

自动剪辑产出的是初稿。省掉的是机械劳动，不是创作判断。

## 踩过的坑（已修）

- **ffmpeg 9 移除了 `-filter_complex_script`** —— 改用通用的 `-/filter_complex <file>` 前缀语法。
  代码里是实测探测，不靠版本号猜。
- **未接线的 filter 标签会让 ffmpeg 直接罢工** —— 卡点模式用 BGM 时若仍给每段建音轨链，
  会报 `output unconnected`。必须先定音源，再决定建不建链。
- **「砍掉多少」的基准** —— 片段只覆盖素材的一部分，用片段之和当分母会把砍掉的部分算丢，
  必须用素材原始时长。
- **`anlmdn` 在本机 ffmpeg 构建里是坏的** —— 最简调用就能复现堆破坏（6/6 崩溃，
  SIGSEGV/SIGABRT），偶尔退出 0 但输出已损坏。已摘除，并有回归护栏禁止回流。
- **淡出必须排在 loudnorm 之后** —— 排前面的话，loudnorm 的动态增益会把淡出重新推上去。
- **`alimiter` 要显式 `level=0`** —— 否则它的自动电平会把 loudnorm 的结果重新拉平。
- **FFT 滤波器有固有延迟** —— afftdn 在 48kHz 下推后 24ms。延迟是实测出来的
  （脉冲探针），不是写死的，否则换档位或换采样率会静默失效。
