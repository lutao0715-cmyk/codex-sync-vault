## 一、平台逻辑（已验证）

**小红书是搜索驱动，不是推荐驱动。** 和抖音是两套完全不同的分发逻辑：

| | 抖音 | 小红书 |
|---|---|---|
| 入口 | 推荐流 | **搜索框** |
| 决定生死的东西 | 前 3 秒钩子 + 完播率 | **标题和正文里的关键词能不能被搜到** |
| 内容寿命 | 3~7 天 | **几个月甚至一年**（长尾搜索流量） |
| 用户意图 | 被推着看 | **主动找答案** |

**由此推出的三条硬规则：**

1. **标题必须包含用户会搜的词**。写"看哭了"没用，写"第一次去崇礼要注意什么"才有用。
2. **"怎么开始">"怎么变强"**。官方数据里两组搜索增长很说明问题：
   - 城市轻户外 +538%、**新手雪山入门 +422%**、**新手滑雪准备什么 +130%**、溯溪必备物品 +1087%
   - 对比：进阶技术类搜索量级明显更小
   → 滑雪号在小红书做「第一次滑雪要买什么」「新手别买这些」「崇礼新手村攻略」，**比做专业拆解有效得多**
3. **内容要可收藏**。清单、避坑、装备表、价格这类"存下来以后用得上"的形式，比情绪片更容易起量（收藏是小红书的强权重指标）

## 二、官方活动（有流量扶持，优先跟）

来源见 skills/热点 的 `xhs_intel.json`，**每次写小红书内容前先查这个文件**（超 30 天要更新）。

已确认的年度级活动：
- **小红书外人节**（户外年度 S 级，前四届 37 亿话题量）——需带 `#小红书外人节#` 发 2 条以上户外笔记
- **户外薯「一起来采秋」**（9-11 月，与各地文旅联动）

对垂类账号来说，**官方活动比热搜榜更有价值**（热搜词多半用不上，官方活动有真实流量倾斜）。

## 三、内容形态（平台通用，待校准）

- **笔记结构**：痛点提问式标题 → 正文前 2 行给答案/结论（搜索摘要会抓这段）→ 分点展开 → 结尾引导收藏
- **长度**：正文 300~600 字，太长用户不看完
- **配图**：首图决定点击率，**图上要有文字**（关键词/数字/对比），不要纯风景
- **标签**：3~6 个，垂类词 + 地域词 + 官方活动词（不带无关热门）
- **口播/视频笔记**：小红书视频的钩子写法与抖音不同——**更偏"教你一件事"而不是"制造冲突"**，节奏更慢，信息密度更重要
