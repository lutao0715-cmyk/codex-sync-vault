## 二、标签习惯（重要，与商单完全相反）

**只用 1~3 个标签。视频号 5 条全部只带一个 `#滑雪`。抖音第 5 条也只带一个 `#滑雪`。**

- `#滑雪` —— 必带，垂类锚点
- `#冬奥会` —— 赛事节点期常带（抖音 4/5 条带）
- 其余一两个随内容走（`#jones_snowboards`、`#相约冰雪一起来`）

**标签位置不固定**：视频号 W1~W4 是 `#滑雪 正文`，W5 是 `正文#滑雪`。说明他不讲究这个。

**和商单对比**：商单脚本里标签一堆（甲方要求覆盖），原创内容标签极简。

**结论**：他自己就懂"标签只决定起跑位置"——**不靠堆标签，靠内容**。**不要给他堆标签的建议。**

## 三、标题写法（真实风格，这里最有价值）

### 3.1 六种定型句式

**① 武侠称号式**（D2）
> 单板滑雪公园之王 公子世无双

前半给"王/神/第一"式称号，后半接文言化补充。**江湖气**。

**② 占位词 + 身份揭示**（D3）
> 他的生活我的梦 滑雪界第一巨富的生活

**一句人人有共鸣的感叹开头**，再用身份点题。经典短视频钩子。

**③ 最高级 + 夸张口语**（D4）
> 全球第一滑雪世家，家族里一个比一个不要命！

**敢用"全球第一""不要命"这种强度词**。

**④ 盘点 + 强度词 + 数字**（D5、W1）
> 滑雪史上最牛逼的十个动作！
> 双板滑雪5大世界纪录

**"史上最牛逼"／"5大" + 数字盘点**。直接、糙、有效。

**⑤ 第一人称情感**（D1，172 万赞爆款）
> 这是我最近听到最让我感动的关于一个人征战冬奥会的故事，希望每个人都能被命运眷顾

**从私人感受切入**（"我最近听到"），落点是祝福。

**⑥ 短句递进 / 反差反问**（W3、W4、W2）**← 视频号这批新增**

> 世界第一人，用滑雪，征服珠穆朗玛峰
> 冬奥会历史第一诈骗犯？最拙劣的运动员？
> 可能是人类历史最震撼的滑雪纪录片之一，征服杀人峰！！

三个特征：
- **逗号切断成短句**，一句一信息，读起来有节奏（不是长定语从句）
- **连续反问制造争议感**（"第一诈骗犯？最拙劣的？"）——故意挑衅，勾评论
- **限定语 + 极端词并置**（"可能是…之一" 后面紧接 "最震撼"、"征服杀人峰！！"双感叹号）——**先留退路再放狠话**

### 3.2 用词特征

| 特征 | 说明 |
|---|---|
| **敢下最高级判断** | "全球第一""第一巨富""史上最牛逼""世界第一人"——**直接下断言，不绕** |
| **口语强度高** | "不要命""最牛逼""诈骗犯"——**带江湖气、糙感，不是精致书面语** |
| **不回避绝对化** | 商单 Brief 明令禁止"最好/首选/第一"，**他自己的标题里"第一"和"最"满地跑** |
| **称号化** | "公园之王""公子世无双""世界第一人"——喜欢给人物封号 |
| **敢用负面/争议词** | "诈骗犯""拙劣""不要命"——**不怕争议，争议本身就是流量** |

> ⚠️ **推翻之前的假设**：从商单提炼的"克制、规避绝对化用语"**完全不是他的风格**，那是甲方要求。

### 3.3 数字的用法

- **标题里的数字都是"盘点结构"**（"十个动作""5大世界纪录""世界第一人"），**不是举证**
- **"数字密集举证"是商单特征**（甲方要卖点支撑），不是他原创标题习惯
- 口播里是否有数字暂无法判断（见第六节局限）

## 四、选题方向（跨 10 条高度一致）

| 方向 | 占比 | 例子 |
|---|---|---|
| **人物传奇 / 极限人物** | **主力** | 世界第一人征服珠峰、单板公园之王、滑雪界第一巨富、全球第一滑雪世家 |
| **纪录片 / 影片解说** | **视频号主力** | 征服杀人峰纪录片、北美滑雪文化电影（W2/W5，尺度最大、最震撼） |
| **盘点 / 榜单** | 常见 | 滑雪史上最牛逼的十个动作、双板滑雪5大世界纪录 |
| **争议 / 反差话题** | 有，评论高 | 冬奥会历史第一诈骗犯？最拙劣的运动员？ |
| **情感故事** | 出爆款 | 一个人征战冬奥会的故事（172 万赞） |
| **赛事节点** | 借势 | 冬奥会相关 |

**底层逻辑：不是教技术，是讲人和故事。**
"谁是这个人""他家为什么这么牛""史上最猛的动作是什么"——**好奇心驱动，不是学习驱动**。

**平台分工正在成形**：
- **抖音** → 人物传奇 + 盘点，覆盖广，标题用称号/最高级
- **视频号** → **纪录片解说**为主（3/5 条），受众更爱长片内容，标题用短句递进 + 争议反问

这跟小红书那条规律（"怎么开始">"怎么变强"）不冲突：抖音靠"想知道"，小红书靠"想学会"，视频号靠"想看完/想转给同好"。

## 五、数据洞察

### 5.1 两种内容线，指标完全不同

**抖音**
| | 情绪型（D1） | 工具型（D5） |
|---|---|---|
| 赞 | 172.3 万 | 2.7 万 |
| 评论/赞 | **≈ 3.6%** | ≈ 0.7% |
| 收藏/赞 | ≈ 1.5% | **≈ 7%** |
| 转发/赞 | ≈ 4.6% | **≈ 14%** |

- **情绪型**（感动、命运）→ **评论远高于收藏**，观众想说话
- **工具型**（盘点、十大气）→ **收藏和转发远高于评论**，观众想存下来、想转给别人

**用法**：想让评论起来 → 情绪；想让转发起来 → 盘点/清单。

### 5.2 视频号的核心信号：转发 > 点赞 ⭐

**W2 / W3 / W4 / W5 四条，转发全部高于点赞**（W4 是 5927 转 vs 3753 赞，**转发是点赞的 1.6 倍**）。

这是**知识/纪录片型内容的典型指纹**——观众不是"随手点赞"，而是"这东西值得转给同样玩雪的人"。

**推论**：
- 视频号内容要做**"可转发性"**：有信息增量、有谈资、有"你看过吗"的社交货币属性
- 反过来看：视频号**不要追求点赞数**，追求转发率。转发的权重在视频号远高于抖音（社交分发逻辑）
- W1（2024-10）是唯一点赞 > 转发的，且数据最大（2.7万赞）→ 说明**大众化选题（世界纪录盘点）更易点赞，深度内容更易转发**

### 5.3 稳定盘

| 平台 | 日常水位 |
|---|---|
| 抖音 | 1.2~2.7 万赞（2025-11 ~ 2026-01 近期作品） |
| 视频号 | 2500~6500 赞（2025-10 近期作品） |

爆款靠选题（人物故事 + 情感落点）突破。

## 六、⚠️ 局限（必须知道）

**这批素材只有标题文案和公开数据，没有口播全文。**

已实测确认两条路都拿不到音频：
- 抖音视频页 → 有播放地址，但页面为 JS 动态加载，未登录抓不稳（涛哥已让放弃这条路）
- **视频号预览页 → 页面里唯一的 `stodownload` 链接返回的是封面图（JPEG 540×720），不是 mp4。移动端 UA 也一样无 `<video>` 标签**

因此：
- ✅ 可以确认：**选题方向、标题写法、标签习惯、用词强度、跨平台差异**
- ❌ 无法确认：**口播的句式、语速、节奏、开头前 3 秒怎么说**

`style-guide.md` 里 L1 层的写作手法（自问自答、口语连接词等）仍然**只有商单来源**，只是"疑似"，**不要当定论**。

**要补口播，只有两条路**：
1. 涛哥直接给视频/音频**文件**（本地文件我能处理）
2. 涛哥把口播文案**贴给我**
