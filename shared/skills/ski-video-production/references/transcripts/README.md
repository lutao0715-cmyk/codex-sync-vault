# 口播语料库（滚动积累）

## 为什么有这个目录

涛哥的旧口播稿已删除，抖音/视频号两条抓取路径也都不暴露音频。
所以口播风格**不再靠一次性收集**——改为**从实际生产中滚出来**。

## 规矩

1. **每次写完脚本、涛哥定稿后**，把定稿存进来，命名：
   ```
   YYYY-MM-DD_平台_标题.md
   ```
   例：`2026-10-03_douyin_世界第一人征服珠峰.md`

2. **成片发布后，如果口播跟定稿有出入 → 以成片为准**覆盖。
   成片才是真实语料，定稿只是过程稿。

3. **攒够 5 条以上**，回头重写 `../style-guide.md` 的 L1 层，
   把"默认不套用"升级为"已确认"。

## 文件里该有什么

```markdown
# <标题>

- 平台：抖音 / 小红书 / 视频号
- 发布：YYYY-MM
- 时长：XX 秒 ｜ 口播字数：XXX 字
- 语速：X.X 字/秒
- 数据：赞 X / 评 X / 藏 X / 转 X

## 口播全文

（逐字稿，保留口语、停顿、重复。不要润色——润色过就不是语料了）

## 备注

（哪一版、改过几次、涛哥自己怎么评价）
```

## 不要做的事

- ❌ 不要为了凑数把过程稿/未定稿存进来（会污染语料）
- ❌ 不要润色口播全文——口语的"毛病"正是风格所在
- ❌ 不要在这里放商单稿（商单进 `../brand-ad-constraints.md`）
