## 第二步：确认三件事

写之前问清楚（缺哪个问哪个，不要瞎猜）：

1. **平台**：抖音 / 小红书 / **视频号**？（三套逻辑完全不同，视频号追转发、小红书追搜索、抖音追点赞）
2. **素材**：实拍有多少？AI 生成占比？（默认 AI ≤ 40%）
3. **时长/体裁**：故事片 / 知识片 / 装备片？目标多少秒？

## 三个出口

### 出口 1 · 写脚本 ✅ 完全能做

产出：
1. 脚本 JSON（`assets/script_schema.json` 的结构）
2. 跑 `scripts/build_script.py` 生成 xlsx 分镜表
3. **必须**附上语速校验结果（脚本会自动算）

```bash
python3 ~/.workbuddy/skills/滑雪出片/scripts/build_script.py \
  --input script.json --output "脚本分镜表.xlsx"
```

硬指标（脚本会自动校验，超了要改）：
- 语速 **4.3 字/秒**（参考安州牧 4.18 字/秒的娓娓道来风格设定，纪录片体裁 4.6 字/秒），超出 ±15% 报警
- 单镜 5~30 秒
- 每镜都要能回答"为什么有这一镜"

### 出口 2 · 配音 ⚠️ 出稿可以，出音频受限

**能做**：配音稿（分段 + 停顿标注 + 重音提示 + 时长估算）
```bash
python3 ~/.workbuddy/skills/滑雪出片/scripts/export_voiceover.py \
  --input script.json --outdir ./配音
```
产出两个 txt：`分段配音稿`（带停顿标记，供逐段生成）+ `纯文本`（整篇）。
涛哥拿分段稿到剪映用「文本朗读」逐段生成，是最顺的路径。

**做不了**：直接生成 MP3。本机没有 `edge-tts`。
如果涛哥要自动配音，需先获授权装依赖（edge-tts 可装进隔离 venv，无需 sudo）。

**反向能力（2026-09-24 新增）**：能**听自己的成片**——把视频文件转成带时间码的
口播稿，并算出语速曲线与停顿图谱，用于校准「按我的风格写」。见文末〈从视频文件学风格〉。

### 出口 3 · 剪辑 ⚠️ 出单可以，动不了时间轴

**能做**：剪辑执行单
- 按镜号列时间码、转场方式、花字内容
- 配乐段落映射（哪个时间段用哪首，取自 `bgm_library.json`）
- 音效点标注
- 素材命名规范（见下方流水线）

**做不了**：真的剪。本机没有 `ffmpeg`。

## 铁律

1. **不编造风格**。没有素材支撑的地方，明说是"我的推断"而不是"你的风格"
2. **商单 ≠ 原创**。做原创内容时不套用品牌资产罗列、卖点砸、搜索引导那套
3. **三个平台分开写**，不做一稿三投
4. **标题敢下狠判断**，用词可以糙（"史上最牛逼""不要命""诈骗犯"）——**不要因为绝对化用语规矩而软化**，那是商单要求
5. **标签只用 1~3 个**，`#滑雪` 必带。**视频号一个就够**。不要建议堆标签
6. **写完自检语速**（4.3 字/秒，纪录片体裁 4.6 字/秒），不靠加快语速凑时长
7. **涛哥改过的稿逐字不改**，返工基于他的版本
8. **视频号内容优先"可转发性"**——有信息增量、能当谈资，别追点赞数

## 附：采集自己的作品（涛哥给链接时用）

```bash
# 抖音
python3 ~/.workbuddy/skills/滑雪出片/scripts/fetch_douyin.py \
  --url https://v.douyin.com/XXXX/ --url https://v.douyin.com/YYYY/ \
  --json originals.json

# 视频号 ⭐ 当前更推荐（稳定、快、不退登录）
python3 ~/.workbuddy/skills/滑雪出片/scripts/fetch_channels.py \
  --url https://weixin.qq.com/sph/XXXX --url https://weixin.qq.com/sph/YYYY \
  --workers 3 --json channels.json
```

原理：本机 Chrome 无头渲染 → 解析渲染后 DOM。**免登录、免签名。**

| | 抖音 | 视频号 |
|---|---|---|
| 可拿 | 文案(desc)、发布时间、赞/评/藏/转 | 文案、作者、发布时间、地点、点赞/转发/推荐/评论 |
| 稳定性 | ⚠️ 页面 JS 动态加载，偶发卡住，需重试 | ✅ 稳定 |
| 耗时 | 30~90 秒/条 | 30~90 秒/条 |

**两者都拿不到口播音频**（视频号预览页只有封面图，无 `<video>`；移动端 UA 也一样）。

**关键工程坑（已解决，改代码时别踩）**：
Chrome 会 fork 子进程并持有 stdout 管道，`subprocess.run(capture_output=True)` 会**永远等不到 EOF**而超时。
必须把 stdout **重定向到文件**再读。

## ⭐ 附：从视频文件学风格（2026-09-24 打通 · 最高优先级素材入口）

线上链接抓不到音频，但**涛哥把视频下载成文件丢过来就行**。本地可直接转录 + 分析节奏。

```bash
python3 ~/.workbuddy/skills/滑雪出片/scripts/transcribe_original.py \
  ~/Desktop/video1.mp4 ~/Desktop/video2.mp4 \
  --model small --workers 3 \
  --outdir ./style-audit/transcripts
```

| 产出 | 内容 |
|---|---|
| `口播全文.md` | 带时间码的口播全文 + 语速曲线 + 停顿图谱 + 剪辑节奏（人读） |
| `analysis.json` | 完整机读数据（写风格档案时读它） |

**技术底座**（别重复踩坑）：
- `faster-whisper` + **PyAV 自带 FFmpeg** → **不需要系统 ffmpeg / brew / sudo**
- venv：`/Users/lutao/.codex/workbuddy-runtime/binaries/python/envs/default`（已装好）
- 环境变量必须先设，否则模型下载 401 失败：
  `HF_ENDPOINT=https://hf-mirror.com`、`HF_HUB_DISABLE_XET=1`
- 速度：i7-8850H 上 `small` int8 ≈ **2.2x 实时**；`base` 更快但中文错字多，**不推荐**
- zhconv 用 pip 装会报 EEXIST → 从 PyPI 下 sdist，把 `zhconv/` 目录整个拷进 site-packages

### 能从视频里读出的风格维度

| 维度 | 对应涛哥问的 | 怎么读 |
|---|---|---|
| 口播全文 | 脚本创作方式 | 逐句转写，看开头钩子、段落结构、收口方式 |
| 语速曲线 | 配音方式 | 每 10 秒窗口的字/秒，看快慢变化 |
| 停顿图谱 | 配音方式 | 句间静音位置与时长 = 气口习惯 |
| 剪辑节奏 | 剪辑方式 | 场景切换检测 → 平均镜长、切换密度 |
| 画面规格 | 剪辑方式 | 竖屏/横屏、分辨率、帧率 |

⚠️ **BGM 会污染转写**——whisper 会把纯音乐段当噪声（VAD 已过滤），但人声 + BGM 混音时
仍可能出错字。**转录稿要对着原片核一遍再当语料用。**
